# Error page assets

뱅기노자 오류 페이지 일러스트레이션. v00.145 부터 사용.

## 파일명 매핑 (가이드 이미지 → 저장 파일명)

| 페이지 | 파일명 | 가이드 이미지 |
|---|---|---|
| 404 페이지 없음 | `404.png` | 노란 길 + 표지판 + 비행기 |
| 500 서버 오류 | `500.png` | 관제탑 + 느낌표 + 비행기 |
| 403 권한 거부 | `403.png` | 자물쇠 + 비행기 trail |
| 401 로그인 필요 | `401.png` | 탑승권 + 사람 아이콘 |
| 네트워크 오류 | `network.png` | 비행기 + 점선 trail |
| 점검 중 | `maintenance.png` | 안전콘 + 렌치 |

각 이미지는 1000×1000 PNG (배경 투명) 권장. 파일이 없으면 페이지 우아하게 fallback (이모지 placeholder).
