## 3. 데이터 모델 변화

기존 cart: `{ version, qty, price }`
신규 cart: `{ bookId, version, qty, price }`

기존 order row: `{ id, userId, version, qty, total, createdAt, status, ... }`
신규 order row: `{ ..., bookId }` — 구주문은 bookId null/빈값 → 폴백 시 BGNJ_BOOKS.primary().title 사용 (1권 가정 시절 호환).

D1 schema: orders 테이블에 `book_id TEXT` 컬럼 — schema-v6.sql 신설. **사용자 수동 적용 필요** (큐 4).
