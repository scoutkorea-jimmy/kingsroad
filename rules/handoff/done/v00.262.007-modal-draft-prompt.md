# v00.262.007 — 모달 외부클릭/ESC 시 [임시저장] / [취소] 명확화

## 사용자 요청 원문

> 자료 입력 시 가끔 외부를 잘못 클릭하면, 그냥 꺼진데. 무조건 다른 곳 클릭하면 임시저장하시겠습니까 를 띄워주고 저장 취소를 띄워줘. 그리고 해당 버튼의 취소 버튼이 안된데. 기능적으로 이슈있는지 한번 더 검토 바람.

## 진단

### 함정 1 — useModalGuard 의 confirm 라벨/의미 역전

[components/Shell.jsx:61](../components/Shell.jsx#L61) `useModalGuard.handleAttemptClose` 가 외부클릭/ESC/뒤로가기 시 호출:

```js
const yes = await fallbackConfirm(
  `${promptName}이(가) 저장되지 않았습니다. 임시저장 하시겠어요?
   [확인] = 임시저장 후 닫기 / [취소] = 그냥 닫기 (변경 내용 버림)`
);
if (yes) saveDraft();
onClose?.();   // ← 둘 다 무조건 닫음
```

- [확인] = 임시저장 + 닫기
- [취소] = **변경 내용 폐기 + 닫기** ← 사용자 직관 어긋남
- 사용자 직관: "취소 = 닫기 행위를 취소 = 모달 유지" → 데이터 잃음 → "취소 버튼이 안 된다" 로 보고됨.

### 함정 2 — ConfirmDialog 백드롭 클릭이 onCancel

[components/ConfirmDialog.jsx:13](../components/ConfirmDialog.jsx#L13):

```jsx
<div role="dialog" aria-modal="true" onClick={onCancel} ...>
```

confirm 떴는데 사용자가 빈 곳 클릭 → onCancel → useModalGuard 의 cancel 분기 → 변경 폐기. **이중 함정**.

### 함정 3 — admin 콘솔 명시적 [닫기] 버튼도 동일 패턴

[pages/AuthAdminPage.jsx:9161-9165](../pages/AuthAdminPage.jsx#L9161-L9165):

```js
<button onClick={async () => {
  const ok = !dirty || (await BGNJ_CONFIRM('… [확인]=임시저장 / [취소]=그냥 닫기'));
  if (ok && dirty) saveDraft();
  onClose?.();
}}>닫기</button>
```

동일 함정. [취소] 누르면 데이터 잃음.

## 변경 방안 (최소 변경 + 사용자 의도 일치)

1. **`components/Shell.jsx` `useModalGuard`** — confirm 라벨 명시 + 의미 반전:
   - 메시지: `"작성 중인 내용이 저장되지 않았습니다. 임시저장 하시겠어요?"`
   - confirmLabel: `'임시저장'`, cancelLabel: `'취소'`, danger: false (gold 강조)
   - 동작:
     - 임시저장 클릭 → `saveDraft()` + `onClose()`
     - 취소 클릭 → **아무것도 안 함 (모달 유지)** ← 핵심 변경
   - `onSaveDraft` 미전달 시(현재 admin 외 4개 모달): 메시지 `"작성 중인 내용이 저장되지 않았습니다. 닫으시겠어요?"` + confirmLabel `'닫기 (변경 폐기)'` + cancelLabel `'취소'`. 취소=모달 유지.

2. **`components/ConfirmDialog.jsx`** — `dismissOnBackdrop` 옵션 추가:
   - 기본 `true` (기존 동작 유지 — 일반 confirm 은 백드롭 dismiss 허용해도 무해)
   - useModalGuard 에서 호출 시 `dismissOnBackdrop: false` 명시 → 백드롭 클릭 무시.
   - `BGNJ_CONFIRM(msg, { dismissOnBackdrop: false })` 지원.

3. **`pages/AuthAdminPage.jsx` ColumnEditorModalContent 닫기 버튼** — 동일 패턴:
   - `BGNJ_CONFIRM` 호출 시 `confirmLabel: '임시저장'`, `cancelLabel: '취소'`, `dismissOnBackdrop: false`
   - 임시저장 → save + close, 취소 → 아무것도 안 함.

4. **검증** — admin 콘솔 칼럼 모달에서 외부 클릭/ESC/닫기버튼 3개 경로 모두:
   - dirty=true: prompt 표시 + [취소] 누르면 모달 유지 + 데이터 보존
   - dirty=false: 즉시 닫힘
   - prompt 위에서 백드롭 클릭: 무시 (prompt 만 닫히는 일 없음)
