# v00.235.000 — 강연·투어 사진 갤러리 (최대 10장 + 출처 + 대표사진)

## 사용자 요청 (이전)
> 강연과 투어프로그램에는 사진을 올릴 수 있게해주고 사진은 최대 10장까지
> 올릴 수 있게해주며, 사진마다 출처와 대표사진을 설정할수있게해줘

## 설계

### 저장 위치 — site_content_kv (worker deploy 회피)
워커 D1 스키마 변경 없이 기존 `site_content_kv` 의 `lecturePages[id]` /
`tourPages[id]` 객체에 `images` 키 추가. v00.075/v00.070 부터 사용해온 패턴
재활용. ★ wrangler deploy 불필요.

```jsonc
// site_content_kv.lecturePages
{
  "lecture-1234567890": {
    "schedule": [...],   // 기존 (보존)
    "notes": [...],      // 기존 (보존)
    "coverDataUri": "...", // 기존 legacy (보존)
    "images": [
      { "url": "https://r2/...jpg", "credit": "© 김작가", "isPrimary": true },
      { "url": "https://r2/...jpg", "credit": "Unsplash", "isPrimary": false }
    ]
  }
}
```

### 표시 우선순위 (cover slot)
1. 갤러리 대표사진 (`images[].isPrimary`)
2. legacy `tour.coverUrl` (D1 column, 투어만)
3. legacy `tourPages[id].coverDataUri` / `lecturePages[id].coverDataUri`
4. CoverPlaceholder

## 변경

### 신규 컴포넌트 `components/MediaGallery.jsx` (~210 줄)
- `MediaGalleryEditor({ value, onChange, folder })` — 모달 안 편집기.
  업로드: `pickImageWithR2Fallback` (admin 번들 helper). 미로드 시
  `BGNJ_LOAD_ADMIN()` 트리거. 썸네일 그리드 88×64 + 출처 input + 대표 라디오 +
  ↑/삭제. 최대 10장 enforce. 첫 사진 자동 대표.
  `_normalizeImages` 헬퍼 — 대표 0개면 첫 번째 강제 / 둘 이상이면 첫 것만 인정.
- `MediaGalleryView({ images, title })` — 공개 페이지 표시. 대표를 0번으로
  끌어올림. 1장이면 미노출. 2장+: `repeat(auto-fill, minmax(180px, 1fr))`
  그리드 + figcaption 출처. lazy-loading.
- `pickPrimaryImage(images)` 헬퍼 + `BGNJ_GALLERY_MAX = 10` 상수.

### `index.html`
`components/MediaGallery.js` script defer 추가 (cache-buster 21곳).

### `pages/LecturesPage.jsx`
- `LectureQuickAddModal`: `images` state (edit 모드면 site_content_kv 에서
  prefill). `<MediaGalleryEditor>` 통합. submit 시
  `BGNJ_SITE_CONTENT.saveSection('lecturePages', { [id]: { ...existing, images } })`
  (기존 schedule/notes/coverDataUri 보존 — 머지).
- 강연 detail cover: `pickPrimaryImage` 우선, 출처는 cover 아래 mono 캡션.
- 강연 본문 (note 아래) `<MediaGalleryView>` — 추가 사진 그리드.

### `pages/WangsanamTourPage.jsx`
동일 패턴. `tourPages[id]` 키. 투어 cover 우선순위: 갤러리 대표 >
`tour.coverUrl` > legacy `coverDataUri`.
