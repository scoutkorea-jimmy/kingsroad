## 1. 사용자 요청 (원문)

> "책 목차에서 지금은 그냥 단순히 줄바꿈을 하면 그냥 줄 바꿈 후 세션이 나뉘어버리는데 - 로 시작하면 해당 세션에 설명(?)이런식으로 넣어주고 규칙에도 추가해줘"

현재 동작: chapters 의 한 줄 = 한 챕터 (강한 구분선). 사용자 의도: `- ` 로 시작하는 줄은 직전 챕터의 sub-item (들여쓰기 설명)으로 표시.

## 3. 그룹핑 로직

데이터: `chapters: ["1부. 시작", "- 첫 번째 길", "- 두 번째 길", "2부. 끝나는 자리", "- 마지막 풍경"]`
파싱:
```js
const groupChapters = (chapters) => {
  const out = [];
  for (const raw of (Array.isArray(chapters) ? chapters : [])) {
    if (typeof raw !== 'string') continue;
    const trimmed = raw.replace(/^\s+/, '');
    if (trimmed.startsWith('- ')) {
      const sub = trimmed.slice(2).trim();
      if (out.length === 0) { out.push({ title: sub, items: [] }); continue; } // 고아 sub: 자체를 챕터로
      out[out.length - 1].items.push(sub);
    } else {
      out.push({ title: raw.trim(), items: [] });
    }
  }
  return out;
};
```

엣지 케이스:
- 첫 줄이 `- ` 로 시작 → "고아 sub". 정책: 자체를 챕터로 격상 (사용자 데이터 손실 방지).
- `- ` 만 있고 내용 없는 줄 → 빈 sub 무시 (filter Boolean 으로).
- 빈 라인 → admin onChange 에서 이미 filter(Boolean) 로 제거됨.

## 4. 렌더 디자인

```
01    1부. 시작
        · 첫 번째 길
        · 두 번째 길
02    2부. 끝나는 자리
        · 마지막 풍경
```

번호는 챕터에만. sub-item 은 들여쓰기 + dim 컬러 + bullet (·) 또는 작은 dot.
