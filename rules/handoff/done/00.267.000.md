# v00.267.000 — 한켠(전주 숙소) 예약 관리 시스템 (PMS)

## 요청
자고 놀자에 뱅기노자 직영 숙소 "한켠" 예약 시스템. 이미지 + 캘린더 + 예약하기 + 예약정보.
→ 확장: 7영역 PMS (객실/요금/예약/재고/고객/결제/운영). 결제는 무통장입금+현장결제.

## 전제
한켠 = 전주 단일 숙소, 여러 객실타입 보유. D1 source-of-truth. 결제 PG 없음(무통장/현장).

## 산출물
- **D1**: `workers/schema-v6-hangyeon.sql` — 9 테이블
  hk_room_types / hk_rate_rules / hk_coupons / hk_availability / hk_bookings /
  hk_booking_log / hk_guests / hk_room_units / hk_payments
- **워커**: `workers/src/index.js` — 28 핸들러 + /api/hangyeon/* 라우트.
  핵심: `hkRoomAvailability`(날짜별 잔여=수량−예약, 오버부킹 방지), `hkComputeStay`(박별요금+연박할인+쿠폰+재고체크), 예약 생성 시 블랙리스트 차단·관리자 알림, 체크아웃 시 방문 +1.
- **클라이언트**: `api.js` BGNJ_API.hangyeon(28 메서드) + `data.js` BGNJ_HANGYEON 헬퍼.
- **프론트**: `pages/HangyeonPage.jsx` (/hangyeon) — 숙소 갤러리(MediaGalleryView) + 객실 카드 + 가용성 캘린더(월 네비, 잔여 표시) + 예약 모달(실시간 견적·개인정보 동의) + 내 예약(상태/취소).
- **관리자**: `pages/admin/HangyeonAdminPanel.jsx` — 7탭
  객실(타입/사진/인원/수량/침대/편의시설/연박할인/판매상태) · 요금(시즌/공휴일/프로모션/요일 규칙 + 쿠폰) · 재고(월 캘린더 + 구간 판매중지/재고/요금 오버라이드) · 예약(필터/상세/상태/결제기록/이력) · 고객(VIP/블랙리스트/방문) · 결제(정산 요약) · 운영(객실단위 공실/투숙/청소/점검 + 오늘 체크인·아웃).
- **연결**: boot.jsx 라우트 'hangyeon' + 타이틀 + ADMIN_SCRIPTS 등록 / index.html HangyeonPage.js 등록 /
  AuthAdminPage '프로그램·쇼핑' 그룹에 "한켠 예약" 탭 + 패널 렌더 / 자고놀자 페이지 한켠 진입 CTA.

## ★ 사용자 수동 단계 (필수 — 안 하면 한켠 예약 동작 안 함)
1. D1 스키마 적용:
   `cd workers && npx wrangler d1 execute banginoja-db --remote --file=schema-v6-hangyeon.sql`
2. 워커 배포:
   `cd workers && npx wrangler deploy`
3. 배포 후: /admin → 프로그램·쇼핑 → 한켠 예약 → 객실 추가 + 사진/요금 등록 → /hangyeon 에서 예약 테스트.
