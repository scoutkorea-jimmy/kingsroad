# v00.234.000 — 관리자 프론트 강연·칼럼·투어 수정

## 사용자 요청 (이전)
> 관리자들은 프론트 페이지에서 강연과 칼럼, 투어프로그램을 수정할 수 있게
> 만들어줘

v00.228 의 add 모달을 prop 으로 add/edit 양 모드 지원하도록 확장 + detail view
에 admin 전용 ✎ 수정 진입로.

## 변경

### `pages/LecturesPage.jsx`
- `LectureQuickAddModal` 에 `initialLecture` prop 추가:
  - `isEdit = !!initialLecture?.id` 분기로 모달 제목/안내문/제출 버튼 라벨 변경
    ("새 강연 추가" ↔ "강연 수정" / "강연 등록" ↔ "강연 저장").
  - 모든 입력 state initial value 가 initialLecture 의 값으로 prefill.
  - `_toLocalInput(iso)` 헬퍼 — ISO startsAt 을 datetime-local "YYYY-MM-DDTHH:mm"
    포맷으로 변환.
  - submit: `id = isEdit ? initialLecture.id : 'lecture-${Date.now()}'`.
    `BGNJ_LECTURES.saveLecture` 가 id 매치 시 update path 분기.
  - audit log action: `lecture.update` ↔ `lecture.create`.
- LecturesPage 본체:
  - `editTarget` state (선택 강연 객체 → 모달 노출).
  - 강연 본문 영역의 badge row 우측에 admin 전용 "✎ 강연 수정" 버튼.
  - 모달 마운트 — `{editTarget && isAdmin && <LectureQuickAddModal initialLecture={editTarget} ... />}`.

### `pages/WangsanamTourPage.jsx`
동일 패턴. `TourQuickAddModal` 에 `initialTour` prop. detail view badge row 에
"✎ 투어 수정" 버튼. audit log `tour.update`/`tour.create` 분기.

### `pages/ColumnPage.jsx`
- `ColumnWriterModal` 에 `initialColumn` prop 추가 — admin 번들의
  `AdminColumnEditor` 가 이미 `initialColumn` 지원하므로 prop pass-through.
- `editColumn` state (선택 칼럼 객체).
- detail view 의 "← 아카이브로" 버튼 행 우측에 admin 전용 "✎ 칼럼 수정" 버튼.
- 모달 헤더 라벨: "새 칼럼 작성" ↔ "칼럼 수정".
