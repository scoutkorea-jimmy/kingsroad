# v00.238.000 — 사이드바 가독성 + 포스터 contain + 빈 강연 토글 유지 + 칩 컬러 + nav PC 가드

> 3. 지난강연은 위가 유지되고 넘어가야 왔다갔다하지...
> 4. 포스터는 다 보이게해줘야지.
> 5. 칩들의 크기로 구분하지 말고, 칩들의 컬러로 구분해.

## 변경

### 1. admin 사이드바 가독성 (`pages/AuthAdminPage.jsx`)
- 버전 뱃지 / `◆ ADMIN CONSOLE` / `contact@bgnj.net` / `DPO` 카드 / 적용법·DPIA
  의 인라인 노란 hex (`var(--primary)` / `rgba(245,213,72,...)` / `--primary-dim`)
  를 모두 ink-2 슬레이트 + bg-3 배경으로 교체. KMS §2 옐로우 5% 룰 정합.

### 2. PC nav 짜부 차단 (`styles.css`)
- v00.236 의 `.nav-menu { overflow-x: auto + 스크롤바 }` 글로벌 룰이 PC 폭에서
  flex 자식 (brand/actions) 의 폭 계산에 영향을 준 의심.
- 룰을 `@media (max-width: 1100px) and (min-width: 721px)` 안으로 격리.
  PC(>1100px) 는 flex-wrap:nowrap 만, 타블렛 폭만 가로 스크롤 활성.
- `.nav-link { white-space: nowrap }` 은 항상 안전 (한글 wrap 차단).

### 3. 빈 강연 본문에서 버킷 토글 유지 (`pages/LecturesPage.jsx`)
- 사용자: "지난강연은 위가 유지되고 넘어가야 왔다갔다하지". 이전엔 `if (!lecture) return ...`
  early-return 으로 빈 분기 진입 시 헤더 + 버킷 토글까지 사라짐.
- 해결: early-return 제거. main return 흐름 유지하고 본문은 `lectures.length === 0`
  분기 카드만 노출 (이미 존재). 헤더/토글/추가 버튼 항상 노출.

### 4. 포스터 짤림 → 자연 비율 + contain (`pages/LecturesPage.jsx` / `pages/WangsanamTourPage.jsx`)
- 사용자: "포스터는 다 보이게해줘야지". 16:10 aspect crop + objectFit:'cover'
  였어서 세로형 포스터 위/아래 잘림.
- cover slot 을 `flex` + `objectFit:'contain'` + `maxHeight:'70vh'` 로 변경.
  포스터 자연 비율 보존, 세로형이 너무 길면 70vh 까지 제한.

### 5. 칩 컬러 카테고리 (`pages/LecturesPage.jsx` / `pages/WangsanamTourPage.jsx`)
- 사용자: "칩들의 크기로 구분하지 말고, 칩들의 컬러로 구분해". 모든 chip 이
  같은 회색 outline 이라 정보 카테고리 안 보였음.
- 카테고리별 색 + 아이콘:
  - 강연 제목 / 난이도 → primary 톤 (`◆`)
  - 결제 (FREE/무통장) → tertiary slate (`₩`)
  - 진행/주최 / 소요 → secondary caramel (`⚐` `⏱`)
  - 장소 / 규모 → info blue (`⌖` `◧`)
