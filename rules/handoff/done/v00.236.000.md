# v00.236.000 — 타블렛 nav 슬라이드 + 강연 hidden 노출 + 포스터 필수

## 사용자 요청 (3건)
> 1. 타블렛에서 보면 메뉴들이 이렇게 짜부되는데, 저렇게 하지말고 비율이 부족하면
>    슬라이드형태로 자동으로 변환되게 해주자
> 2. 강연 등록해놓은게 있는데 왜 노출이 안되냐
> 3. 강연은 대부분 포스터가 있으니까 포스터 꼭 등록할 수 있게해줘야해

## 변경

### 1. `styles.css` — Nav 슬라이드 (타블렛 폭 짜부 차단)
- `.nav-menu` 에 `flex-wrap: nowrap` + `overflow-x: auto` + `min-width: 0` +
  `-webkit-overflow-scrolling: touch`. 가는 스크롤바 (3px / `var(--line)`) 적용.
- `.nav-link` 에 `white-space: nowrap` + `flex-shrink: 0` — 한글 메뉴 라벨이
  글자별로 wrap 되어 세로로 짜부되던 문제 차단.
- 720px 이하는 햄버거 모드라 `.nav-menu { display:none }` 가 우선 → 영향 없음.

### 2. `pages/LecturesPage.jsx` — 강연 미노출 진단 + 수정
- 사용자 보고 "등록한 강연이 안 보인다" 의 가장 유력한 원인 2가지:
  (a) 강연이 hidden 으로 등록됨 (admin 도 프론트에서 listAll() 기본은 hidden 제외).
  (b) refresh 시 워커 응답 비-배열 (v00.231 가드 발동, console.warn).
- 해결:
  - `listAll({ includeHidden: isAdmin })` — admin 은 hidden 강연도 노출.
  - 강연 detail badge 행에 `hidden` 시각 라벨 ("◆ 숨김 (관리자에게만 보임)" /
    warning 톤). 일반 회원은 라벨 자체가 안 보임 (강연이 listAll 에서 제외됨).
  - 진입 시 1회 강제 `BGNJ_LECTURES.refresh({ includeHidden: true })` +
    `bgnj-lectures-refresh` 이벤트 청취 (ColumnPage v00.134 패턴). 데이터 로드
    누락 차단.
- `LectureQuickAddModal` 에 `hidden` state + 토글 추가 — admin 이 임시 저장 시
  사용. 저장 시 `saveLecture({ ..., hidden })` 반영.

### 3. `pages/LecturesPage.jsx` — 포스터(대표 사진) 필수
- `LectureQuickAddModal.submit()` 가드: `if (!images || images.length === 0)
  { setError('강연 포스터(대표 사진)는 최소 1장 등록해야 합니다...'); return; }`
- 갤러리 편집기 아래 안내 문구: "* 강연 포스터(대표 사진) 최소 1장 등록 필수.
  첫 사진이 자동으로 대표가 됩니다."
- v00.235 갤러리 인프라 그대로 활용.

### 4. `pages/WangsanamTourPage.jsx` — 동일 패턴 (투어)
- `listAll({ includeHidden: isAdmin })` + 진입 refresh + 이벤트 listener.
- detail badge 에 hidden 시각 라벨.
- `TourQuickAddModal` 에 `hidden` 토글 추가.
- **포스터 필수는 미적용** — 사용자가 강연만 명시.
