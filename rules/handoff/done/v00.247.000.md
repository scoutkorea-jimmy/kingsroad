# v00.247.000 — 히어로 배경 이미지 (PC/모바일 별도 업로드)

## 사용자 요청
> 히어로 세션의 배경화면을 설정할 수 있도록 해줘. 설정탭에서 이미지를 올릴 수 있게해주고, 모바일과 PC버전을 각각 올릴 수 있게해줘. 이미지가 올라간게 없으면 지금처럼 아무것도 없는 배경화면을 보여주면 좋을듯

## 변경

### 1. HomePage.jsx hero section
- `home-hero` `<section>` 안에 absolute 배경 div 2개 (PC/모바일) 추가
- `hero` 객체의 `bgDesktopUrl` / `bgMobileUrl` 읽기 — 비면 렌더 X (현재 모습 유지)
- 기존 컨텐츠 wrapper 에 `position:relative; z-index:1` (배경 위에)

### 2. styles.css
- `.hero-bg-image` 공통 base (absolute inset 0, background-size cover, center)
- `.hero-bg-desktop` — PC 전용 노출
- `.hero-bg-mobile` — 모바일(≤600px) 전용 노출
- @media query 로 분기

### 3. AdminContentEditors.jsx HeroEditorPanel — 콘텐츠 카드에 업로드 슬롯 2개
- `pickImageWithR2Fallback` (folder='hero-bg') 사용
- PC 슬롯: 미리보기(120×90 16:9-ish) + 업로드 + 삭제
- 모바일 슬롯: 미리보기(60×100 9:16-ish) + 업로드 + 삭제
- contentDraft.bgDesktopUrl / bgMobileUrl 저장 → site_content_kv.hero 의 일부로 함께 commit

### 4. 동작
- 둘 다 미설정: 현재처럼 빈 배경 (변경 없음)
- PC만 설정: 데스크톱은 이미지, 모바일은 빈 배경
- 모바일만 설정: 모바일은 이미지, PC는 빈 배경
- 둘 다 설정: 각각 viewport 에 맞춰 노출
