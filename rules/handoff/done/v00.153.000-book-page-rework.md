## 3. 구현 단계

1. nav/메뉴 라벨 grep → 정의 위치 찾고 텍스트 교체. SEO/title 도 함께.
2. BookPage 의 현재 단일 책 가정을 다권 가정으로 확장:
   - `BGNJ_BOOKS.list({status:'published'})` → primary 우선 정렬
   - 상단에 탭 (책이 ≥2권일 때만 노출). 선택된 책의 id state.
   - 선택 책의 모든 표시 필드 (제목/부제/저자/표지/판본 가격/탭 콘텐츠) 가 그 책 기준.
   - admin 변경 즉시 반영 — `bgnj-books-refresh` event 청취.
   - URL 동기화 (`?p=book&id=<bookId>`): 시간 허용 시 추가, 우선은 state 만.
3. 책 제목 수정: D1 데이터이므로 admin 에서 사용자가 편집하도록 답변에 안내. **단, 사용자가 표지에 보이는 "아는 만큼 재밌어"가 정확한 새 제목인지 + 부제는 무엇인지 확인 필요** — 임의 추정 금지. (코드가 표지·제목 mismatch 의 root cause 가 아니라는 확인까지가 코드 작업의 범위)
4. 버전 bump v00.152.000 → v00.153.000 + cache-buster + ADMIN_VERSION_HISTORY entry
5. 빌드 → commit → push
