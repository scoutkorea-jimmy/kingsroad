## 진단

### 인프라 이미 보유 (변경 최소화 가능)

`components/TiptapEditor.jsx` 는 `column` 또는 `rich` preset 일 때:
- [line 60-64](../components/TiptapEditor.jsx#L60) — Image extension 활성 (`inline:false, allowBase64:true`)
- [line 147-166](../components/TiptapEditor.jsx#L147) — `insertInlineImage()` 가 파일 선택 → `BGNJ_MEDIA.uploadFile()` 로 R2 업로드 → 본문에 `<img src=URL>` 삽입
- [line 293-297](../components/TiptapEditor.jsx#L293) — 툴바에 "🖼 본문 이미지" 버튼 노출
- StarterKit (v3) 가 `Dropcursor` 기본 포함 → ProseMirror 가 이미지 드래그/드롭 위치 표시 자동 제공
- ProseMirror 의 `Image` node 자체가 draggable — 사용자가 grab 으로 끌어 위치 이동

R2 폴더 분기:
- preset='column' → `column-images` (admin 전용)
- preset='rich'   → `post-images` (사용자 허용 폴더 — `requireUser` 분기, 일반 로그인 회원 OK)
