# v00.284 — 한켠 객실 주간/월간 상품 추가

## 요청
객실관리에 **주간 상품**·**월간 상품** 추가. 현재는 시간제(hourly) + 숙박/하루(nightly)만 존재.

## 결정 (사용자 확인)
- **기간**: 고정 1블록. 주간 = **7박 고정**, 월간 = **30박 고정**. 손님은 시작일만 선택, 반복 불가.
- **요금**: 주/월 **정액 직접 입력**(관리자가 1주 요금, 1개월 요금 입력). 장기할인은 정액에 녹임.
- **월 기준**: 30박 고정.

## 모델 요약
주간/월간 = 고정 N박(7/30) 연속 점유 + 정액 요금. 본질은 nightly의 고정-기간·정액 변형.
점유는 기존 per-night 재고(`hkRoomAvailability`, 범위 점유)를 그대로 재사용 → 더블부킹 방지 자동.
쿠폰·회원할인은 정액 위에 적용. rate rule/주말가/연박할인은 미적용(정액 상품).

## 변경 파일
### 1) D1 스키마 — `workers/schema-hangyeon.sql` + 마이그레이션
`hk_room_types` 컬럼 추가: `weekly_enabled`, `weekly_price`, `monthly_enabled`, `monthly_price`.
신규 `workers/migrate-weekly-monthly.sql` (ALTER TABLE ADD COLUMN ×4) — **사용자가 remote 적용**.

### 2) 워커 — `workers/src/index.js`
- `hkMapRoomType`: weeklyEnabled/weeklyPrice/monthlyEnabled/monthlyPrice 직렬화.
- 신규 `hkComputeFixed(env, roomTypeId, unit, checkIn, rooms, couponCode, isMember)` — 7/30박 정액 견적.
- `hkQuoteFor`: unit weekly|monthly → hkComputeFixed 라우팅.
- `hkHourRemaining` dayRow SQL: 종일 점유에 `'weekly','monthly'` 포함(`nightly` IN-list 확장). (hkRoomAvailability 는 이미 범위 점유라 OK.)
- `handleHkDay`: weeklyAvailable/weeklyTotal/monthlyAvailable/monthlyTotal 계산해 카드에 전달.
- `handleHkBookingCreate`: checkOut 을 `q.checkOut` 우선 사용(weekly/monthly 는 body.checkOut 없음). 알림 메시지도 변수 사용.
- `handleHkRoomTypeCreate` INSERT + `handleHkRoomTypePatch` map: 4컬럼 추가.

### 3) 관리자 — `pages/admin/HangyeonAdminPanel.jsx`
- `blank()`: weeklyEnabled:false, weeklyPrice:0, monthlyEnabled:false, monthlyPrice:0.
- 편집 폼: 시간제·하루 카드 옆에 **주간(7박)**·**월간(30박)** 카드(토글 + 정액 요금).
- 목록 요약줄: 주간/월간 요금 표기.

### 4) 손님 — `pages/HangyeonPage.jsx`
- `HkBookingModal`: unit 목록 동적 구성(nightly/weekly/monthly/hourly), 토글 2개 이상일 때 노출.
  weekly/monthly 선택 시 체크아웃 자동(+7/+30박) 읽기전용 표시, quote/book payload `{unit, checkIn, rooms:1}`.
- `HkRoomCard`: available 에 weekly/monthly 포함, 주간/월간 요금 칩 표시.

### 5) 릴리스
data.js 무변경(payload passthrough). 버전 00.284.000 + index.html 캐시버스터 + ADMIN_VERSION_HISTORY + 워커 배포 + 마이그레이션 안내.

## 검증
- 관리자: 객실에 주간/월간 토글+요금 저장 → 재조회 반영.
- 손님: 주간/월간 선택 → 체크아웃 자동 7/30박, 정액 견적, 예약 접수.
- 더블부킹: 주간 예약 후 해당 7박 구간 nightly/hourly 재고 차감 확인.
