## 변경 목록

### A. 섹션 박자 부수기

| 섹션 | 기존 헤더 | 새 헤더 |
|---|---|---|
| 추천 | `SectionHead` (eyebrow+title+subtitle+action) | `SectionHead` 유지 (앵커) — 단 카드 그리드는 asymmetric (첫 카드 2x) |
| 투어 | `SectionHead` 동일 | **inline 헤더** — 한 줄 (eyebrow + title + 카운트 + ghost action). subtitle 제거 |
| 커뮤니티 | `SectionHead` 동일 | eyebrow 만 + 한 줄 title. subtitle/action 인라인 우측 |
| 칼럼 | `SectionHead` 동일 | featured 카드 안에 헤더 통합 (magazine spread 톤). 외부 SectionHead 제거 |
| 강연 | `SectionHead` 동일 | eyebrow 만 + 가로 스크롤 (3열 grid → 가로 카드 row) |
| 책 CTA | (없음, 카드 자체) | hero 톤 인 (eyebrow + 큰 타이틀 + 표지) — 현재 1:1 grid 유지하되 padding/scale 강화 |

### C. 카드 form factor 다양화

- **추천 (grid-3 → grid asymmetric)**: 첫 카드 2칸 차지 (사진 자리 더 크게), 나머지 2 카드 작은 1칸. 'editorial spread' 인상.
- **투어 (grid-2 카드)**: 카드 유지, 단 좌측 큰 번호 (`一·二·三·四`) 를 카드 안으로 흡수해 'index page' 톤. 기존 `0X` mono 번호는 유지(사용자: 모노 그대로).
- **커뮤니티 (flat row)**: 현재 row 유지. 양쪽 padding 만 살짝 축소 (24px → 20px) 해서 컴팩트.
- **칼럼 (1.3:1 featured + sidebar)**: featured 카드 padding 30 → 48, 헤드 카피를 카드 안에 absorb. sidebar 는 카드 라인 제거 → 텍스트 list (구분선만).
- **강연 (grid-3)**: **가로 스크롤** — `overflow-x:auto` + `flex` row, 카드 폭 280px 고정. 'film strip' 인상.
- **책 CTA**: padding 72 → 96, gap 60 → 80. 더 hero 답게.

### E. 주제 / 지원 2그룹 위계

기존: 모든 `.section` = 120px padding (동일).

새 그룹:
- **주제 (강한 들이마심)**: 추천, 책 CTA → padding 140px 0 (큰 호흡)
- **지원 (가벼운 내쉼)**: 투어, 강연 → padding 80px 0 (`section-tight` 사용)
- **읽기 (중간)**: 커뮤니티, 칼럼 → padding 100px 0 (신규 modifier `section-mid` 추가)

CSS 신규 modifier:
```css
.section--anchor { padding: 140px 0; }
.section--mid { padding: 100px 0; }
.section-tight 는 기존 80px 그대로 사용
```

### 부가 정리

- `.section-head` 의 `align-items: flex-end` → 인라인 헤더 variant (`.section-head--inline`) 추가: gap 작게, subtitle 인라인.
- 강연 가로 스크롤용 클래스 `.lecture-strip` (overflow-x:auto, scroll-snap, 모바일도 스크롤 유지).
- 추천 asymmetric grid 클래스 `.grid-feature-2` (1.6fr 1fr 1fr, 첫 자식 row-span-2).
