# v00.228.000 — 관리자 프론트 강연/투어 quick-add

## 사용자 요청
> 관리자 권한을 가진 계정들은 프론트 페이지에서도 강연과 투어 프로그램을
> 추가할 수 있도록 만들어줘

기존: 강연·투어 추가는 `AuthAdminPage` (관리자 콘솔) 안의 `LectureAdminPanel` /
`TourAdminPanel` 에서만 가능. 일반 강연·투어 페이지(`LecturesPage`,
`WangsanamTourPage` 의 `TourPage`) 에는 신청/예약 UI 만 있고 추가 진입로 없음.

## 변경 요약

### 1. `pages/LecturesPage.jsx`
- `LecturesPage` 안에 `isAdmin = !!user?.isAdmin` + `addOpen` state 추가.
- ＋ 강연 추가 버튼 노출 위치 2곳:
  - **버킷 토글 행 우측** (`marginLeft:'auto'`) — 평상시 진입로.
  - **빈 상태 카드 안** — 사이트에 강연이 0개여도 admin 이 추가할 수 있게.
- 신규 컴포넌트 `LectureQuickAddModal`:
  - 필드: 제목 (필수), 주제, 장소, 진행, 일시 (필수), 소요 분, 정원, 참가비, 안내.
  - 기본값: `+1주 19:00`, durationMinutes 90, capacity 30, price 0,
    host '뱅기노자' — `AuthAdminPage.addNewLecture` 의 default 와 동일.
  - 저장: `BGNJ_LECTURES.saveLecture(...)` → `BGNJ_AUDIT.log` →
    `BGNJ_BROADCAST.publish('lectures')` → `onSaved()` (페이지 refresh).
  - `useModalGuard` 로 ESC + body lock + 외부 클릭 처리. `dirty` 는 사용자가
    title/topic/venue/note 중 하나라도 입력했을 때 true.
- export 에 `LectureQuickAddModal` 추가.

### 2. `pages/WangsanamTourPage.jsx`
- `TourPage` 안에 `isAdmin` + `addOpen` state 추가.
- ＋ 투어 추가 버튼 노출 위치 2곳:
  - **탭 행 위쪽** (justifyContent:'flex-end') — 평상시.
  - **빈 상태 카드 안** — 0개일 때.
- 신규 컴포넌트 `TourQuickAddModal`:
  - 필드: 제목 (필수), 부제, 난이도, 소요 표시, 규모 표시, 출발 일시 (필수),
    소요 분, 정원, 참가비, 소개.
  - 기본값: `+2주 10:00`, durationMinutes 180, capacity 12, price 80000 —
    `AuthAdminPage.addNewTour` 의 default 와 동일.
  - 저장: `BGNJ_TOURS.saveTour(...)` (priceNumber + price 둘 다 전송 →
    worker `parsePrice` 의 priceNumber 우선 처리) → audit log → broadcast →
    `onSaved()`.
- export 에 `TourQuickAddModal` 추가.

### 3. 권한 게이팅
- 버튼 자체는 `isAdmin` 일 때만 렌더 (UI 보호).
- 모달은 `addOpen && isAdmin` 더블 체크 (state 조작 우회 차단).
- 실제 권한 검증은 워커 `requireAdmin` 이 `handleLectureCreate` /
  `handleTourCreate` 진입 시 수행 — 비-admin 의 직접 API 호출은 401/403.

## 후속
- 본 quick-add 는 **상세 편집 진입 안 함** — 등록 후 admin 패널에서 진행/참고/
  커버/환불정책 등을 보강해야 함. UX 트레이드오프: 프론트에서 모든 필드를
  보여주면 모달이 비대해져 "빠른 추가" 가치 상실.
- 후속 사이클 후보: 등록 직후 `?p=admin&tab=강연&edit=<id>` 로 자동 이동해
  상세 편집 화면 진입 (사용자 신호 시).
