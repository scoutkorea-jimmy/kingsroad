# v00.279.000 — 커뮤니티 3대 결함 일괄 수정

1. `/community` 진입 시 **Minified React error #300** — "이 페이지를 불러오던 중 오류가 발생했습니다".
2. **페이지 5번 이후로 안 넘어감.** "06. 김제시" 이전 옛 글들이 안 보임 → "게시글이 삭제된거야?"
3. **모든 서브메뉴(메가 드롭다운)가 영역 안에서 잘림.** "서브메뉴는 영역 밖에서 보여야지".

## 진단 (근본 원인)

### ① React error #300 — hook 순서 위반
`pages/CommunityPage.jsx` 의 `CommunityPage` 컴포넌트:
- `if (postId) { ... return <상세> }` early return (726~762)
- **그 뒤에** `useState(movingPostId)`, `useCallback(handleMovePost)`, `useState` ×4 (reorder),
  `useEffect`, `useMemo` ×2 등 **9개 hook 이 호출됨** (774~931).
- 목록뷰(postId null) ↔ 상세뷰(postId 있음) 전환 시 실행되는 hook 개수가 달라짐
  → React error #300 ("Rendered fewer hooks than expected") → 트리 크래시.

### ② 게시글이 안 보임 — fetch limit 50
- `workers/src/index.js:480` `limit = Math.min(Number(...|| 50), 200)` → 기본 50, 최대 200.
- `data.js refreshPosts()` 가 `posts.list(opts)` 를 **limit 없이** 호출 → 최신 50개만 로드.
- 게시글당 10개 페이지 = 정확히 **5 페이지**. 51번째 이후(옛 글)는 fetch 자체가 안 됨.
- **D1 실측: posts 85건 존재 — 삭제 아님.** 단지 표시 한계.

### ③ 메가 드롭다운 잘림 — overflow 클리핑
- `.nav-menu { overflow-x: auto }` (가로 슬라이드용, styles.css:971).
- CSS 규격상 한 축이 visible 아니면 다른 축도 clip → 세로로 뜨는 `position:absolute` 드롭다운이 잘림.
- "놀자"(`.nav-mega-play`) 만 v00.266 에서 JS `position:fixed` 로 탈출. 커뮤니티 메가는 미적용.

## 수정

1. **CommunityPage.jsx** — `if (postId)` 상세 early-return 블록을 모든 hook/파생값 **아래로** 이동.
   → hook 은 항상 동일 개수 실행, 조건부 return 은 hook 이후.
2. **data.js refreshPosts** — `posts.list({ limit: 1000, ...opts })` 로 넉넉히 요청 (opts override 허용).
3. **workers/src/index.js** — list limit 기본 1000 / 캡 2000 으로 상향 후 배포.
4. **Shell.jsx Nav** — 메가 드롭다운 제어를 play 전용 → 범용(`openMega` key)으로 일반화.
   커뮤니티 메가도 `position:fixed` + JS 위치계산으로 overflow 탈출. styles.css hover 규칙 정리.
