현재 `.btn` 정의가 `border-radius` 미지정 (브라우저 기본 0) → 완전 사각. 그림자/lift 도 없음 → "wireframe / AI 생성 mockup" 느낌. 자연스럽게 = subtle rounded + 미세 그림자 + hover 살짝 떠오름.

## 2. 진단

[styles.css:951-977](styles.css#L951) `.btn` 정의 — `padding 14px 28px`, `transition all .25s`, **border-radius 0**, **box-shadow 0**.

비교용 다른 요소의 radius:
- `.theme-toggle` 4px
- `:focus-visible outline` 2px
- `.card` / `.field-input` / `.section` 모두 0 — sharp 디자인 언어 일관

→ **카드는 그대로, 버튼만 살짝 부드럽게** 하면 시각 위계가 살고 인터랙티브 요소가 더 도드라짐. 카드와 명확히 다른 element type 임을 시각적으로 전달.

## 4. 디자인 결정

- **`border-radius: 8px`** — 6 vs 8 vs 10 사이. 6 = 너무 보수적, 10 = 약간 over-rounded. 8 이 modern + subtle (Stripe / Linear / Vercel 트렌드). 카드 sharp 와 의도적 대비.
- **그림자** subtle: `0 1px 2px rgba(0,0,0,0.04)` rest → `0 4px 12px rgba(0,0,0,0.08)` hover. Gold 버튼은 gold-tint shadow 로 브랜드 호흡.
- **hover lift**: `translateY(-1px)` — 사용자가 마우스 올렸을 때 살짝 떠오르는 micro-interaction. 인터랙티브함의 시각 시그널.
- **active**: `translateY(0)` + 그림자 작게 — 누르는 느낌.
- **transition**: `all .2s cubic-bezier(.2,.7,.2,1)` — 약간 ease-out 한 자연스러운 동선.
- **a11y**: `prefers-reduced-motion: reduce` 시 transform 비활성화. focus outline border-radius 도 8px 로 일치.
- **다크모드**: 그림자 alpha 가 작아 dark/light 둘 다 자연스러움. 별도 override 미필요.
