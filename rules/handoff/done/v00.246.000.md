## 진단

### A. 슬라이드 느낌 X
v00.240 자동 순환은 `setFeaturedIdx((i) => (i + 1) % length)` — React 즉시 re-render. CSS 트랜지션 없어 그냥 swap. 사용자 시점에선 깜빡임만 보임.

### B. 높이 변동
[HomePage.jsx:1008-1021](pages/HomePage.jsx#L1008-L1021):
- 커버 이미지 있는 칼럼: `height: 340px`
- 커버 이미지 없는 placeholder: `height: 260px`
- → 80px 차이, 5초마다 깜빡거리며 점프
- 추가로 title (h2) line-height 1.2 무제한 + excerpt 무제한 → 각 칼럼별 수직 길이 다름

### C. 제목 길이 들쭉날쭉
[HomePage.jsx:1032](pages/HomePage.jsx#L1032): `<h2>...</h2>` 자르기 없음.
[HomePage.jsx:1077](pages/HomePage.jsx#L1077): `<h4>{c.title}</h4>` 자르기 없음.
짧은 제목(8-12자) 은 그대로, 긴 제목(30+) 은 자동 wrap 으로 2줄. → 사용자 보고 "어떤건 다보이고 어떤건 요약". excerpt 만 `slice(0, 65)` 적용.

## 변경

### 1. 슬라이드 애니메이션 (styles.css 신규 keyframes)
```css
@keyframes bgnj-column-slide-in {
  from { opacity: 0; transform: translateX(28px); }
  to   { opacity: 1; transform: translateX(0); }
}
.column-featured-slide { animation: bgnj-column-slide-in 0.5s ease-out; }
```
featured `<article>` 에 `key={featuredIdx}` + `className="column-featured-slide"` — 매 idx 변경 시 unmount/mount 로 애니메이션 재생.

### 2. 높이 안정화
- **커버/플레이스홀더 height** 340/260 → **320 통일** + `marginBottom 28→24` 정합
- **featured `<article>`** `min-height: 600px` — 짧은 칼럼도 일정 높이 유지 (점프 방지)
- **title** 20자 cut: `truncatePreview(title, 20)` 또는 길이 비교 후 `…` append
- **excerpt** 65자 → 80자 cut + `min-height` (2줄 분량 안정화)
- **secondary list 항목** title 20자 cut + 각 row `min-height: 90px`

### 3. 제목 20자 통일
- `truncatePreview` 헬퍼 ([HomePage.jsx:186](HomePage.jsx#L186)) 재사용 — 이미 lecture/tour 카드에서 110자 컷 용도로 사용 중
- featured 와 secondary 모두 `truncatePreview(title, 20)` 적용
