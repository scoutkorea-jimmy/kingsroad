## 3. tooltip 디자인

- 카드 hover (또는 키보드 focus-within) → 카드 우측 (또는 화면 끝이면 좌측) 에 popover 패널 노출
- popover: bg var(--bg), border var(--gold-dim), shadow, padding 14, min-width 220
- 내용: 카드별 `details` 배열을 label / value 표 형태 (label dim, value mono gold)
- 노출 상태는 React state (idx 기반, 한 카드만 동시 노출). onMouseEnter/Leave + onFocus/Blur
- a11y: `aria-describedby` + popover 에 `role="tooltip"`. 키보드만으로도 보임

## 7. 남은 위험

- 모바일 hover 미지원 — popover 가 첫 탭에 보이고 두 번째 탭에 클릭 동작 (UX 약점). v00.157 1차는 desktop hover 만 정상, 모바일은 부제로 fallback.
- popover 내 데이터는 클라이언트 derived. 정확도는 BGNJ_* 헬퍼의 데이터 신선도에 의존.
- z-index 충돌 — 카드 popover 가 사이드바·헤더 보다 위. z-index 상위 값 부여.
