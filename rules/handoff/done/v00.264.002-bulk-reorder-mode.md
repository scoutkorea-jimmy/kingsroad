# v00.264.002 — 게시글 순서 편집 모드(드래그앤드롭 + 일괄 저장)

## 사용자 요청 원문

> 게시글 순서를 여러개 한번에 바꾸고 싶을 떄에는 어떻게 할 수 있지?

## 진단

- v00.264.001 의 ▲▼ 버튼은 1칸씩만 이동. 여러 항목을 한 번에 재배치할 때는 클릭 횟수가 많아 불편.
- 단일 클릭 기반 ▲▼ 는 매번 서버 호출 + refreshPosts → 일괄 작업에 비효율적.

## 변경 방안

### "✎ 순서 편집" 토글 모드 (admin · sort=latest 전용)

1. 게시판 상단 ADMIN 안내 박스 옆에 토글 버튼 노출.
2. 모드 ON:
   - `localOrderIds` 가 현재 페이지 게시글 id 배열을 스냅샷.
   - 각 행이 `draggable=true` + dragstart/dragover/drop 핸들러 → 끌어서 위치 변경.
   - 드래그 중인 행 opacity ↓, drop 가능 행 위쪽 보더 강조.
   - ▲▼ 버튼은 모드 ON 동안 숨김.
   - 페이지네이션은 모드 ON 동안 잠금 (페이지 이동 시 변경 사항 소실 위험).
3. 하단에 "저장 (변경 N건)" / "취소" 버튼 노출.
4. 저장:
   - 현재 페이지 위/아래 경계 게시글의 createdAt 을 anchor 로 잡고, N개 게시글을 그 사이에 균등 분배한 ISO timestamp 생성.
   - 위치가 바뀐 항목만 `Promise.all(BGNJ_API.posts.update(id, {createdAt}))` 로 병렬 호출.
   - 완료 후 `refreshPosts()` 1회.
5. 취소: 변경 있으면 confirm → localOrderIds 폐기.

### 페이지간 이동

- 본 사이클은 페이지 내 재배치만 지원. 페이지 간 이동은 별 신호 없으면 ▲▼ 1칸 이동 누적으로 대응 가능.
- 향후 신호 시 "맨 위로 ⤒ / 맨 아래로 ⤓" 단축 버튼 추가 검토.
