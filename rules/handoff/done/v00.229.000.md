## 변경

### 1. `boot.jsx` — `/error?code=…` 라이브 라우트
- `VALID_ROUTES` 에 `'error'` 추가.
- 신규 `case "error":` 가 `URLSearchParams` 로 `code` 읽고 매핑:
  - `401` → `Error401Page`
  - `403` → `Error403Page`
  - `404` → `Error404Page` (default)
  - `500` → `Error500Page`
  - `network` → `ErrorNetworkPage`
  - `maintenance` → `ErrorMaintenancePage`
- 기존 admin 미리보기 패널 (`ErrorPagesPreviewPanel`, AuthAdminPage:4105) 외에
  사용자 직접 진입 + 어드민→회원 안내 링크 공유 가능.

### 2. `boot.jsx` — `/mypage` 401 wiring
- 기존: `MyPage` 가 비로그인이어도 그대로 렌더 (`user?.id` 옵셔널 체인으로
  반쯤 빈 상태 노출).
- 신규: `if (!user) { return <Error401Page/> }` 라우트 진입 가드.

### 3. `boot.jsx` — `/admin` 권한 분기 세분화
- 기존: `if (!user?.isAdmin) return <AdminDenied/>` (비로그인/비관리자 한 처리).
- 신규: 비로그인 → `Error401Page`, 로그인했지만 비-admin → `AdminDenied` (이메일
  표시 UX 보존).

### 4. `BookCheckoutPage`
변경 없음. 자체 inline 비로그인 안내가 이미 책 정보를 함께 보여주는 맥락-친화적
UX 라 유지 (강제 표준화로 정보 손실 방지).
