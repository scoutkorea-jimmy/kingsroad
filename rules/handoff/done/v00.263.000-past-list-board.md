# v00.263.000 — 지난 투어/지난 강연 = 게시판 행 목록 (클릭 시 상세)

## 사용자 요청 원문

> 투어프로그램이 이전 투어프로그램은 페이지로 보이지 말고, 게시판 형태로 목록으로 보이게 해주고 목록을 클릭하면 해당 게시물(투어)가 보일 수 있게해줘. 강연도 동일

## 진단

현재 (v00.262.009):
- LecturesPage / WangsanamTourPage 모두 `upcoming` / `past` 버킷 분리됨
- past 버킷도 **upcoming 과 동일한 UI**: 상단 가로 탭(0X · 제목) + 하단 본문 grid (커버 + 정보 + 사이드바)
- 사용자: "지난" 것들은 신청 동선이 의미 없고 카드 뷰가 시각적으로 무거움 → **행 단위 게시판 목록**이 훨씬 적합

## 변경 방안

### 구조 (양 페이지 공통)

- `bucket === 'upcoming'`: 기존 탭+그리드 그대로 (회귀 0)
- `bucket === 'past'`:
  - **목록 모드 (기본)**: 행 단위 테이블/리스트. 한 행 = 한 투어/강연.
    - 컬럼: 일시 · 제목/부제 · 규모 또는 형식 · 카운트(후기) · 액션(자세히)
    - 행 클릭 → 해당 id 의 **상세 모드** 전환
  - **상세 모드**: 기존 그리드 그대로 (커버 + 정보 + 사이드바) + 상단 "← 목록으로" 버튼
    - 신청 패널(BookingPanel)은 past 라도 그대로 표시 (후기/사진 등 상호작용 가능)

### state

- 신규: `pastDetailId` (null = 목록 모드 / id = 상세 모드). 버킷 전환·페이지 mount 시 reset.
- `selectedIdx` 는 past 모드에서 pastDetailId 와 1:1 동기 (기존 코드 재활용).

### 외부 진입

기존 sessionStorage(`bgnj_pending_tour_id` / `bgnj_pending_lecture_id`) 처리에서 past 버킷으로 분기될 때는 `pastDetailId` 도 set → 즉시 상세 모드.

### 게시판 행 디자인 (간결, 기존 토큰 사용)

```
일시        제목                                  규모      후기   ▶
2026.04.12  창덕궁 후원 답사 — 정조의 효심을 따라    12인 이하  4건   →
2026.03.05  종묘 야간 답사                          10인 이하  2건   →
```

- 행 호버 시 배경 살짝 강조 (`var(--bg-2)` rgba)
- 모바일에서는 컬럼 일부 (규모/후기) 숨김 — 일시 + 제목 + ▶ 만
- 클릭 영역 전체 → role=button + cursor:pointer + Enter/Space 키 처리
