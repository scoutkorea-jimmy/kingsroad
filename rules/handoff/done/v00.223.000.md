## 진단 (현재 상태)

코드 점검 결과 모바일 가독성에 영향을 주는 6가지 약점:

| 영역 | 현재 | 문제 |
|---|---|---|
| 본문(.post-body) phone | 16px / 1.85 | 한글 prose 16px는 작음. 17px 권장 |
| 입력 폼(.field-input) | 14px | iOS Safari focus 시 16px 미만이면 자동 zoom 발생 |
| iframe / video embed | 미지정 | 폭 고정 / 비율 깨짐. YouTube 임베드도 부모 폭 안 따름 |
| .dim-2 메타 (--ink-3) | #64748B | 야외/햇빛에서 흐림 (특히 폰 화면) |
| .section-eyebrow / mono 라벨 | letter-spacing 0.2em + 10px | 좁은 폰 폭에서 자간 과해 줄 깨짐 |
| .card-title 22px on phone | 22px | 카드 폭 좁을 때 줄바꿈 다수 |

## 개선안 (v00.223 — CSS only, 코드 변경 없음)

### A. 본문 읽기 (post-body)
- ≤600px: font-size 16 → **17px**
- p + p 단락 간격 1em (호흡)
- 헤딩 line-height 1.3

### B. 입력 폼 (iOS auto-zoom 차단)
- ≤600px: `.field-input` / `textarea` / `select` font-size **16px**
- padding 살짝 컴팩트 (13px 14px)

### C. 미디어 임베드 (보기 + 듣기)
- 데스크톱·모바일 공통: `.post-body iframe`, `.post-body video`
  - `width: 100%`, `aspect-ratio: 16/9`, `height: auto`
- YouTube/Vimeo 임베드 + 강연 영상 모두 부모 폭에 맞게 반응형

### D. 메타 텍스트 가독성 (≤600px)
- `.dim-2` color → `var(--ink-2)` (한 단 진하게)
- `.section-eyebrow` letter-spacing 0.2em → 0.1em, font-size 11px
- `.badge` / `.pill` font-size 10 → 11px, letter-spacing 0.1em

### E. 카드 / 제목 호흡 (≤600px)
- `.card` padding 20 → 22px 20px
- `.card-title` 22 → 20px (line-height 1.3)
- `.section-title` 26 → **28px** (mute 보다 또렷)
- `.footer li` 13 → 14px

### F. 태블릿(≤900px) section-title 30px (32 → 30 살짝 톤다운)
