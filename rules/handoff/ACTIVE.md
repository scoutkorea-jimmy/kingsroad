### 커뮤니티 게시판 현황

`notice`(공지) · `free`(자유) · `question`(질문) · `info`(정보) · `column`(칼럼) · `어`(언론보도)

- **`column` 게시판은 글이 0개인 빈 껍데기.** 진짜 칼럼 72편은 별도 `/column` 페이지에 있다. → 삭제 대상.
- **`언론보도` 게시판의 id 가 `어` 로 잘못 들어가 있다.** 한글 id 는 URL·세션 키에서 문제를 일으킬 수 있음.

### 챗봇이 쓸 데이터 소스

- `window.BGNJ_LECTURES.listAll()` · `window.BGNJ_TOURS.listAll()` · `window.BGNJ_COLUMNS.listPublic()`
- 날짜 해석은 `startsAt` → 없으면 `next` 텍스트(`.` → `-` 치환). [HomePage.jsx:135](../../pages/HomePage.jsx#L135) `_eventTs` 와 같은 규칙.
- 상세 진입은 `sessionStorage` 펜딩 키 — 강연 `bgnj_pending_lecture_id`, 투어 `bgnj_pending_tour_id`.
  칼럼은 펜딩 키 없이 `/column` 로 이동 ([Shell.jsx:540](../../components/Shell.jsx#L540) `goAndClose` 패턴).

## 3. 개편안

### 메뉴 (7개 → 5개)

```
홈 │ 자고 놀자 │ 답사·투어 │ 배움 ▾ │ 커뮤니티 ▾
                              ├ 강연      ├ 자유 · 질문 · 정보 · 공지
                              └ 도서      ├ 뱅기노자 칼럼      ← 메뉴 이동
                                          ├ 한켠역사문화포럼    ← 신설(사용자 작업)
                                          └ 언론보도
```

**URL 은 전부 유지한다** (`/lectures` `/book` `/column` 각각 살림).
메뉴만 묶고 통합 페이지에서 탭 전환. 이유 — 칼럼 72편의 검색 유입과 `#col-N` 앵커가 안 깨지고 구현 위험이 낮다.

### 우하단 위젯

```
                    ┌──────────────┐
                    │ 무엇을 도와  │
                    │ 드릴까요?    │
                    │ ▸ 가장 빠른 강연 일정 │
                    │ ▸ 가장 빠른 답사 일정 │
                    │ ▸ 가장 최근 칼럼     │
                    └──────────────┘
                              [↑]  ← Top (위로 밀림)
                              [💬] ← 챗봇 (신규)
```

**AI 없음.** 이미 메모리에 있는 헬퍼를 읽어 정해진 답을 만든다. 서버 호출·비용·지연 0.

**핵심 설계 판단 — 예정이 0개인 현실을 전제로 만든다.**
그냥 만들면 3개 중 2개가 "없습니다"로 끝난다. 그래서:

> 예정 있으면 → 제목 + 날짜 + `보러 가기`
> 예정 없으면 → "지금 예정된 강연은 없습니다. 지난 강연 N회 기록을 보실 수 있어요" + `지난 강연 보기`

**빈손으로 돌려보내지 않는 것이 이 위젯의 존재 이유다.**
