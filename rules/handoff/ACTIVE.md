## 3. 개편안

### 메뉴 (7개 → 5개)

```
홈 │ 자고 놀자 │ 답사·투어 │ 배움 ▾ │ 커뮤니티 ▾
                              ├ 강연      ├ 자유 · 질문 · 정보 · 공지
                              └ 도서      ├ 뱅기노자 칼럼      ← 메뉴 이동
                                          ├ 한켠역사문화포럼    ← 신설(사용자 작업)
                                          └ 언론보도
```

**URL 은 전부 유지한다** (`/lectures` `/book` `/column` 각각 살림).
메뉴만 묶고 통합 페이지에서 탭 전환. 이유 — 칼럼 72편의 검색 유입과 `#col-N` 앵커가 안 깨지고 구현 위험이 낮다.

### 우하단 위젯

```
                    ┌──────────────┐
                    │ 무엇을 도와  │
                    │ 드릴까요?    │
                    │ ▸ 가장 빠른 강연 일정 │
                    │ ▸ 가장 빠른 답사 일정 │
                    │ ▸ 가장 최근 칼럼     │
                    └──────────────┘
                              [↑]  ← Top (위로 밀림)
                              [💬] ← 챗봇 (신규)
```

**AI 없음.** 이미 메모리에 있는 헬퍼를 읽어 정해진 답을 만든다. 서버 호출·비용·지연 0.

**핵심 설계 판단 — 예정이 0개인 현실을 전제로 만든다.**
그냥 만들면 3개 중 2개가 "없습니다"로 끝난다. 그래서:

> 예정 있으면 → 제목 + 날짜 + `보러 가기`
> 예정 없으면 → "지금 예정된 강연은 없습니다. 지난 강연 N회 기록을 보실 수 있어요" + `지난 강연 보기`

**빈손으로 돌려보내지 않는 것이 이 위젯의 존재 이유다.**

- 티커 신설 — 최근 칼럼 제목이 흐른다. 0편이면 미렌더. `prefers-reduced-motion` 에서 정지 + 가로 스크롤.
- **반전 블록** — 좌 최신 칼럼(종이빛) / 우 최신 답사(잉크). 다크에서 오던 대비를 여기 한 번에 몰았다.
- **통합 기록 목록** — 칼럼·답사·강연을 날짜순 한 줄로. 이전엔 세 섹션이 따로 있어
  `아이브로우→제목→전체보기→카드` 리듬이 세 번 반복됐다. 유형은 우측 태그로만 구분.
- 제거: 칼럼 캐러셀 섹션 · 투어 그리드 섹션 · 강연 스트립 섹션 (통합 목록이 대체).
  각 상세는 `/column` `/tour` `/lectures` 로 계속 연결되므로 기능 손실 없음.

**작업 중 잡은 버그** — `recentEntries` 를 `lectures` 선언보다 위에 넣어
`Cannot access 'lectures' before initialization` 발생. PageErrorBoundary 가 잡아 흰 화면은 면했고,
선언 순서를 고쳐 해결. **2-tier ErrorBoundary 가 실제로 작동한 사례.**
