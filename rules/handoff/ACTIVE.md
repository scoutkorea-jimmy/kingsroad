실제로는 **모두에게 그대로 보인다** — 가려진 게 아니라 안 가려진 것이다.
회원이 오해하고 있을 수 있으니 안내가 필요하다.

# 3부 — 사용자 여정 Sankey 폐기, 경로 순위표로 (v00.309.000)

## 1. 지시 내역 (사용자 원문)

> 유입 채널 → 단계 → 대표 도착 페이지
> 이 그래프가 너무 뭉쳐져있기도 하고 이렇게 되면 보는 의미가 없어서 그래.
> 나는 좀 3단계 혹은 그 이상으로 구분해서 유의미한 인사이트를 얻으려고하는거야

## 2. 진단 — 문제는 그림이 아니라 **데이터 모양**이었다

`flowPairs` 는 `(referrer_host, route)` **쌍**을 200개까지 세는 것이었다.

**쌍은 순서를 모른다.** 한 사람이 `홈 → 광장 → 홈` 으로 움직여도
`(직접,홈)` `(직접,광장)` `(직접,홈)` 세 쌍으로 흩어져 세어졌다.
'A 다음에 B 로 갔다' 가 원본에 없으니 **칸을 몇 개로 늘리든 인사이트가 안 나온다.**
뭉쳐 보인 건 결과였지 원인이 아니었다.

## 3. 고친 것 — 세션 하나를 한 줄로 편다

```sql
ROW_NUMBER() OVER (PARTITION BY session_id ORDER BY ts, id)
```

유입 채널 → 첫 화면 → 다음 → 그다음. 세 번째까지 적고 뒤는 '계속'.
같은 경로끼리 묶어 세션 수 순으로 상위 15개.

⚠ **유입 채널은 첫 페이지의 referrer 만 본다.** 세션 전체에서 고르면
내부 이동(`bgnj.net`)이 유입 채널로 둔갑한다 — 실제로 처음 짤 때 그렇게 나왔다.
`bgnj.net`·`self`·빈 값은 '직접 방문' 으로 접는다.

```
  4  m.search.naver.com › 광장
```

⚠ `localhost:8899` 같은 개발 트래픽이 섞여 있다. 운영 데이터라 **숨기지 않았다** —
걸러내려면 별도 판단이 필요하다.

## 4. 남긴 것 / 뺀 것

- `SankeyFlow` 는 `AdminShared.jsx` 에 **그대로 남아 있다.** 되돌리려면 한 줄이면 된다.
- 서버의 `flowPairs` 도 계속 계산한다 — 다른 소비자가 생길 수 있어 끊지 않았다.
- 화면 이름을 사람 말로 옮기는 표(`ROUTE_LABEL`)를 새로 뒀다. 새 화면을 만들면 **여기에도 추가할 것.**
  빠지면 영문 route 가 그대로 노출된다(막히지는 않는다).

## 5. 곁다리로 확인한 것 — 카드는 **모든 사람의 숫자**를 센다

사용자가 "내가 작성한게 아니라 오늘 작성된, 모든 숫자들을 달라는거야" 라고 확인을 요청했다.
집계 SQL 에 작성자 조건이 **없다**. 실측으로도 확인:

```
오늘(KST) 댓글 6건 — 쓴 사람 2명   ← 한 사람 것만 세면 나올 수 없는 숫자
오늘 글 0건 · 글 공감 6건 · 방문 9세션
```

⚠ 처음 대조할 때 **UTC 자정으로 잘라 전부 0 이 나왔다.** 한국 자정은 `2026-08-25 15:00 UTC` 다.
`kstDayStartUtc()` 를 쓰지 않고 손으로 자르면 아침 9시 이전 활동이 통째로 빠진다.
