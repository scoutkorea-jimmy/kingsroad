## 1. 지시 내역 (사용자 원문 요지)

1. 최상단에 `CLAUDE.md` 를 만들고, `rules/` 폴더를 신설해 **모든 규칙을 그 안에** 둔다.
   목적은 효율 — Claude 가 사이트 전체를 뒤지지 않고 **적절한 규칙 파일과 행 위치를 찾아** 확인하게 한다.
2. 모든 작업은 `rules/` 에 **handoff 문서**를 만들어 지시 내역을 기록하고, 작업을 시작하고,
   끝나면 **작업 완료로 기록**한다. 이유: **PC가 바뀌어도 끊김 없이 업무를 잇기 위함.**
3. **디자인 디렉토리**를 만들고 홈페이지 전체 UI를 개편한다.
4. 사진은 **모두 관리자 페이지에서 올리고 관리**할 수 있게 한다. **지금은 비운 채로** 넣는다.
5. (중간 지시) 메인화면에서 커뮤니티 섹션을 뺀다. → v00.288.003 완료.
6. (중간 지시) 자리를 비우니 선택 요청 없이 진행한다.

## 4. 사용자 직접 작업 (코드로 못 하는 것)

**히어로 배경 이미지를 비우는 것은 D1 `site_content_kv` 값 변경이라 코드로 할 수 없습니다.**
"지금은 비운 채로" 지시를 완성하려면 관리자에서 직접 해주셔야 합니다.

1. **관리자 → 사이트 콘텐츠 → 히어로 → PC 배경 / 모바일 배경 `비우기`**
   현재 값:
   - `bgDesktopUrl` = `.../api/media/hero-bg/d2153ea97e693399243112ee.png`
   - `bgMobileUrl` = `.../api/media/hero-bg/487b4dfe96faa66ff55009a7.png`
   비우면 배경 일러스트가 사라지고 여백형 히어로가 됩니다. 사진을 넣으면 자동으로 사진형이 됩니다.
2. **관리자에 저장된 `heroStyle` 이 있으면 옐로우가 그대로 보일 수 있습니다.**
   기본값은 `--secondary` 로 바꿨지만 관리자 저장값이 우선합니다.
   라이브 확인 결과 현재는 정상 반영됐습니다 — 저장값이 없었던 것으로 보입니다.
3. **히어로용 사진 확보** — 가로형 3~5장, **폭 2,000px 이상**.
   기존 자산은 기준 미달입니다 (§ `design/README.md` 참조).
