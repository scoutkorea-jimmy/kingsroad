## 3. 개편안

### 메뉴 (7개 → 5개)

```
홈 │ 자고 놀자 │ 답사·투어 │ 배움 ▾ │ 커뮤니티 ▾
                              ├ 강연      ├ 자유 · 질문 · 정보 · 공지
                              └ 도서      ├ 뱅기노자 칼럼      ← 메뉴 이동
                                          ├ 한켠역사문화포럼    ← 신설(사용자 작업)
                                          └ 언론보도
```

**URL 은 전부 유지한다** (`/lectures` `/book` `/column` 각각 살림).
메뉴만 묶고 통합 페이지에서 탭 전환. 이유 — 칼럼 72편의 검색 유입과 `#col-N` 앵커가 안 깨지고 구현 위험이 낮다.

### 우하단 위젯

```
                    ┌──────────────┐
                    │ 무엇을 도와  │
                    │ 드릴까요?    │
                    │ ▸ 가장 빠른 강연 일정 │
                    │ ▸ 가장 빠른 답사 일정 │
                    │ ▸ 가장 최근 칼럼     │
                    └──────────────┘
                              [↑]  ← Top (위로 밀림)
                              [💬] ← 챗봇 (신규)
```

**AI 없음.** 이미 메모리에 있는 헬퍼를 읽어 정해진 답을 만든다. 서버 호출·비용·지연 0.

**핵심 설계 판단 — 예정이 0개인 현실을 전제로 만든다.**
그냥 만들면 3개 중 2개가 "없습니다"로 끝난다. 그래서:

> 예정 있으면 → 제목 + 날짜 + `보러 가기`
> 예정 없으면 → "지금 예정된 강연은 없습니다. 지난 강연 N회 기록을 보실 수 있어요" + `지난 강연 보기`

**빈손으로 돌려보내지 않는 것이 이 위젯의 존재 이유다.**

## 10. 조용히 넘기던 오류 전수 검토 (v00.294.009 — 완료·배포됨)

빈 `catch {}` 318곳을 전부 뽑아 **try 안에서 무엇을 하려던 것인지**로 분류했다.
전부에 warn 을 박는 건 소용없다 — 사용자가 손해 보는 자리만 고치고, 의도적으로
조용해야 하는 자리는 그렇다고 표시해 다음 점검이 의미를 갖게 했다. **318 → 135.**

|---|---|

| 등급 '기본값 복원' | 서버 저장이 **전부 실패해도 '복원 완료'** 라고 표시. 등급은 권한의 기준이라 운영자가 잘못된 전제로 다음 설정을 만진다 |
