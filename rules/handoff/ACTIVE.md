## 10. v00.304.001 — 후속 (2026-08-23)

### 사용자 보고 3건

1. **"분류가 이동이 안 되는 것 같다" → 실제로는 칸이 좁아 글자가 접힌 것**
   `신지식 청년사관` 이 `신지식 청 / 년사관` 으로 **어절 중간에서** 끊겼다.
   `.badge` 에 `white-space: nowrap` 이 없었다 — 한글 줄바꿈은 어절 단위가 원칙인데 배지가 예외였다.
   · `.badge` · `AuthorGradeBadge` 에 `nowrap` · 분류 칸 90 → 132 · 작성자 칸 120 → 172.
2. **작성자 칸도 같은 문제** — `백승기 / [뱅기노자 관리팀]` 로 배지가 아래로 내려갔다. 위와 같이 처리.
3. **"김유미는 왜 혼자 편수관이야?"** — 아래 §11.

### 내 코드의 결함 하나 — 시리즈가 0개로 잡혔다

시리즈 판정을 **게시판 설정의 말머리 목록** 기준으로 만들었는데, 운영에서는
**글에만 일괄 적용하고 게시판 설정에는 등록하지 않은 상태**가 나왔다.
그 상태로는 말머리가 멀쩡히 붙은 글 14편이 통째로 안 묶인다 — 시리즈 0개.
→ 기준을 **글에 실제로 달린 말머리**로 바꿨다. 설정은 순서(=주소 순번)를 정하는 데만 쓴다.
같은 이유로 커뮤니티 목록 필터·글쓰기 선택지도 `mergeBoardPrefixes()` 로 둘을 합친다.

**교훈** — 설정과 데이터가 어긋난 상태를 '있을 수 없는 일' 로 두면 안 된다.
사람이 두 곳에 따로 입력해야 하는 구조라면, 한쪽만 채워진 상태가 반드시 나온다.

## 12. v00.305.000 — 말머리 태그 · 수정 이력 (2026-08-23)

### 지시 (사용자 원문)

> 말머리는 글 작성 시 선택할수 있게해줘.

|---|---|
| 태그가 글에 붙는 방식 | **글 쓸 때 태그 칸에 채워 준다** — 그 뒤로는 여느 태그와 같아 작성자가 빼고 더할 수 있다 |

### 설계 판단 — 말머리 정의에 태그를 함께 담는다

후자를 골랐다. 워커는 `prefixes_json` 을 `JSON.stringify` / `JSON.parse` 만 하고 내용을 보지 않아서,

읽는 곳 전부: 커뮤니티 목록 필터 · 글쓰기 선택 버튼 · 관리자 게시판 설정 · `tools/seo-build.mjs`.

## 14. v00.306.000 — 게시판 이동이 '안 되는 것처럼' 보인 이유 · 태그 쳐서 찾기 (2026-08-24)

### 지시 (사용자 원문)

> 그리고 태그도 있으면 기존꺼 검색되어서 보게 하라고햇지 왜 안되는거야?

### 보고 1 — 이동은 **되어 있었다.** 화면이 옛 이름을 그렸다

서버 실측(`GET /api/posts`)에서 바로 드러났다.

```

#132 → 같음 · #129 → 같음
```

`posts` 는 게시판을 **두 벌**로 들고 있다 — `category_id`(진짜)와 `category`(글 쓸 때 박아 넣은 이름).
워커 `handlePostPatch` 는 이동 시 **id 만** 고쳤고, 관리자 목록은 **이름**을 그리고 있었다.
그래서 DB 는 옮겨졌는데 화면만 안 옮겨진 것처럼 보였다.

같은 결함을 v00.295 에 홈에서 한 번 만났고(게시판 이름을 바꾸면 옛 이름이 남는다),
그때는 **홈 한 곳만** `_boardLabel(categoryId) || p.category` 로 고쳤다.
나머지 여섯 곳은 그대로였다 — 그래서 이번에 관리자에서 다시 터졌다.

**교훈 — 파생값을 한 곳에서만 고치면 나머지가 반드시 다시 터진다.**
공통 헬퍼로 올리고 호출부를 전수로 바꿔야 끝난다.
