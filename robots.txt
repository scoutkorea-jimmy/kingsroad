# v00.306.006 — `/*?p=/admin` 형태를 각 그룹에 함께 적는다.
#   GitHub Pages 는 /admin 에 404.html 을 주고, 그 파일이 `/?p=/admin` 으로 돌린다.
#   그 주소는 **경로가 `/` 라 `Disallow: /admin` 에 걸리지 않는다** — 직접 집으면 200 이 나온다.
#   robots.txt 는 어차피 '부탁' 이므로, 화면 자체도 <meta name="robots" content="noindex"> 를
#   달게 했다(boot.jsx applyRobotsMeta). 둘 다 있어야 한다.
