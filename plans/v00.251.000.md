# v00.251.000 — 히어로 카드 다크 텍스트 복원 + 배경 이미지 opacity 낮춤

## 사용자 보고 (2건)
1. (직전) HeroProgramCards 안 텍스트 안 보임 — v00.250 의 has-bg 라이트 매핑이 카드 안 텍스트까지 검정으로 만들어 다크 카드(--bg) 위에 가려짐
2. **(새 보고)** "하이어라키는 이제 좋은데 배경에 글씨가 묻히는 문제는 여전히 발생중임"

## 변경

### 1. 카드 안 ink 토큰 다크모드 본래 톤 복원
```css
:root[data-theme="dark"] .home-hero.has-bg .home-program-card {
  --ink: #F1F5F9; --ink-2: #94A3B8; --ink-3: #64748B;
}
```
hero 일반 영역은 검정 텍스트(라이트 매핑) / 카드 안은 흰 텍스트(다크모드 복원).

### 2. 배경 이미지 자체 opacity 낮춤 (가독성 root 해결)
v00.249 의 흰 그라디언트만으로 부족. 노란 태양/일러스트 colors 가 너무 강해 텍스트 contrast 부족.

```css
.hero-bg-image { opacity: 0.5; }
@media (max-width: 600px) {
  .hero-bg-image { opacity: 0.4; }
}
```

PC 0.5 / 모바일 0.4 — 이미지가 완전 사라지지 않으면서 colors 약화 → 검정 텍스트가 또렷하게 살아남. 옐로우 accent 도 흰 배경 위에서 더 뚜렷.

## 변경 파일
- `styles.css` (카드 토큰 복원 + opacity)
- `data.js` / `version.json` / `index.html`

## 효과
- **가독성**: 노란 태양/일러스트 약화 → 텍스트 우선
- **카드**: 다크 카드 위 흰 텍스트 정상 노출
- **이미지**: 살아있되 텍스트 보조 역할로 전환
