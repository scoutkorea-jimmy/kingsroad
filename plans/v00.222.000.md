# v00.222.000 — 모바일 게시글 목록 가독성 (제목 1줄 + 메타 라인)

## 사용자 민원
> 모바일에서 게시글 목록을 보면 제목이 너무 짤려보인데
> 제목을 한 줄로, 그 밑에 작은 글씨로 다른 정보들을 보여주는게 좋아보여

## 현재 구조 (문제점)
- `pages/CommunityPage.jsx` 의 게시글 목록은 6칸 `<table>` (번호/분류/제목/작성자/조회/날짜)
- 모바일 ≤900px 에서 6열을 그대로 유지 → 제목 칸이 좁아져 텍스트가 강제 줄바꿈/잘림
- 제목 옆에 ★북마크 + 📷이미지 + ♥좋아요 + #태그 + HOT/NEW 인라인 → 좁은 폭에 더 압박

## 변경 방안 (모바일 ≤900px)
1. 비-제목 컬럼(번호/분류/작성자/조회/날짜) thead·tbody 모두 `display:none`
2. 제목 td 한 칸만 풀폭 노출
3. 제목 td 내부 2줄 구조:
   - **1줄째 (제목)** — `nowrap + text-overflow:ellipsis` 1줄 자르기. ★북마크 + 제목 + HOT/NEW 만 인라인 유지
   - **2줄째 (메타, 데스크톱에선 숨김)** — `[분류] · 작성자 · 날짜 · 조회 ♥좋아요 📷이미지` 작은 글씨 + dim 톤

## 구현 단계
1. `pages/CommunityPage.jsx`
   - `<table>` 에 `className="community-table"` 부여
   - 각 `<th>` / `<td>` 에 컬럼 식별 클래스 (`col-num` `col-cat` `col-title` `col-author` `col-views` `col-date`)
   - 제목 td 내부:
     - title 줄: `<span className="row-title-text">` 로 감싸 ellipsis 적용 가능하게
     - 메타 줄: `<div className="row-mobile-meta">` 신규 — 분류/작성자/날짜/조회 + 카운트 배지
2. `styles.css` — `@media (max-width: 900px)` 블록 안:
   - `.community-table .col-num, .col-cat, .col-author, .col-views, .col-date { display: none; }`
   - `.community-table .col-title { display: block; padding: 14px 0; }`
   - `.community-table .row-title-text { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; display: block; }`
   - `.community-table .row-mobile-meta { display: flex; gap: 8px; flex-wrap: wrap; ... }`
   - 기본(데스크톱) `.row-mobile-meta { display: none }`
3. 버전/배포
   - `data.js` BGNJ_VERSION → 00.222.000
   - `version.json` → 00.222.000
   - `index.html` cache-buster `?v=00.221.000` 21곳 → `?v=00.222.000`
   - pre-commit 훅이 build / csp / version check / lint 자동 처리
4. commit + push (auto-deploy)

## 검증
- 데스크톱: 기존 6열 테이블 변화 없음
- 모바일 (≤900px): 제목 1줄 ellipsis + 메타 라인 노출
- ColumnPage / 다른 페이지에는 영향 없음 (`.community-table` 으로 스코프)
