# v00.205+ — alert() → BGNJ_TOAST / 모달 마이그레이션

## 배경
디자인 가이드(AdminDesignHub.jsx)는 "alert() 금지 — 인라인 박스 또는 토스트 사용" 을 원칙으로 명시. 하지만 실제 코드는 **AuthAdminPage.jsx 에 33회 alert() 호출**이 남아 있어 가이드와 정면 충돌. v00.204 디자인 가이드 동기화 시 발견.

## 작업 범위

### 1. AuthAdminPage.jsx alert() 33건 일괄 교체
- `alert('실패: ' + msg)` → `window.BGNJ_TOAST.error(msg, { code: 'ADMIN_*' })`
- `alert('성공')` → `window.BGNJ_TOAST.success(msg)` 또는 인라인 골드 박스
- 분류:
  - **저장/삭제/숨김 실패** (≈20건): toast.error
  - **저장 성공** (≈8건): toast.success
  - **확인 다이얼로그** (≈5건 `window.confirm` 동반): SuspendDialog 패턴 ConfirmDialog 컴포넌트로 통일

### 2. ConfirmDialog 공통 컴포넌트 추가
- `components/ConfirmDialog.jsx` — title / body / 확인 버튼 라벨 / onConfirm prop
- SuspendDialog 의 모달 패턴 그대로 차용
- 다른 페이지에서도 재사용 가능

### 3. 다른 페이지 점검
- BookCheckoutPage / LecturesPage / WangsanamTourPage / MyPage 도 alert 잔여 검색
- 발견 시 동일 교체

## 안전 가드
- 한 번에 다 바꾸지 말고 **카테고리별 묶음 PR** (저장/삭제/확인 별도 커밋)
- 각 교체 후 admin 패널에서 실제 동작 확인
