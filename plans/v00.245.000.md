# v00.245.000 — 투어/강연 모달 갤러리 다크모드 가독성 정합

## 사용자 요청
> 투어프로그램 관련해서도 마찬가지로 사진들이 들어갈 수 있게 해야하고 UI들이 안깨지게 넣어줘. 지금도 첨부한 이미지처럼 깨지잖아

(스크린샷: 다크모드 TourQuickAddModal 의 사진 갤러리 영역이 깊이감 없이 평평하게 보여 "깨진" 느낌)

## 진단

투어 사진 추가 기능은 v00.235 에 이미 구현 (MediaGalleryEditor). 깨짐의 root cause:

| 영역 | 현재 색상 | 다크모드 hex | 문제 |
|---|---|---|---|
| 모달 컨테이너 | `var(--bg)` | `#0F172A` | — |
| 갤러리 wrapper | `var(--bg-2)` | `#1E293B` | 모달과 약 contrast 차 (10%) |
| **드롭존 inside** | `var(--bg)` | `#0F172A` | **모달 bg와 동일** → 평면화 |
| 드롭존 border | `var(--line-2)` | `#475569` | 약함 |

다크모드에서 "갤러리 영역" → "드롭존" 의 시각 위계가 무너지면서 dashed border 만 둥둥 떠 있고 그 내부가 모달 배경과 흡수되어 깨진 인상. 라이트 모드에선 미세하게 보이나 다크모드에서 결정적.

## 변경 (MediaGallery.jsx 만 수정 — 한 곳에서 양쪽 모달 동시 정합)

1. **드롭존 background** — `var(--bg)` → `var(--bg-3)` (라이트 #F1F5F9 / 다크 #334155)
   - 양 모드 모두 wrapper(`--bg-2`)보다 밝게 → 영역 구분 명확
2. **드롭존 border** — `2px dashed var(--line-2)` 유지하되 다크모드에서 visibility 위해 padding 약간 키움 (18/14 → 20/16)
3. **dragOver 상태** — 더 또렷한 옐로우 tint (0.08 → 0.12) + border solid primary
4. **wrapper border** — `--line` → `--line-2` 한 단 강화
