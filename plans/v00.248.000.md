# v00.248.000 — 히어로 모바일 배경 PC 이미지 자동 fallback

## 사용자 보고
> 모바일에서는 배경화면 들어가도 적용이 안되네. 지금 배경화면이 첨부한 이미지 같은
> 스타일이고, PC버전 적용은 첨부한 이미지처럼 되어있으니 최대한 느낌을 비슷하게 살릴
> 수 있게 모바일버전 최적화 진행해줘

## 진단

v00.247 의 모바일 배경 동작:
- HomePage.jsx 가 `hero.bgMobileUrl` 이 truthy 일 때만 `.hero-bg-mobile` 렌더
- 사용자가 PC 이미지만 업로드 → `bgMobileUrl` 비어있음 → 모바일 div 미렌더 → 빈 배경

근본 원인: PC/모바일 슬롯이 **완전 분리** 되어 있어 한 쪽만 업로드 시 다른 쪽이 빈 배경. 사용자 의도는 "최대한 느낌 비슷" — 즉 모바일에서 PC 이미지를 자동으로 활용하길 기대.

## 변경

### 1. HomePage.jsx — 모바일 fallback
- `.hero-bg-mobile` div 의 url 을 `bgMobileUrl || bgDesktopUrl` 로 fallback
- PC URL 도 둘 중 하나라도 있으면 렌더 (즉 모바일만 업로드해도 PC 에 노출)

### 2. AdminContentEditors HeroEditorPanel — UX hint 추가
- 모바일 슬롯 라벨/hint 에 "비워두면 PC 이미지가 모바일에서도 사용됩니다" 명시
- 사용자가 무엇을 기대해야 하는지 즉시 인지 가능

### 3. styles.css — 모바일 hero 미세 조정
- 모바일에서 cover/center 가 한국풍 모티프 가운데를 잘 살리도록 background-position 살짝 조정
- 모바일 hero section min-height 보강 (배경이 충분히 노출)

## 동작 매트릭스 (수정 후)

| PC 슬롯 | 모바일 슬롯 | PC viewport | 모바일 viewport |
|---|---|---|---|
| 비움 | 비움 | 빈 배경 | 빈 배경 |
| **업로드** | 비움 | PC 이미지 | **PC 이미지 (fallback)** |
| 비움 | 업로드 | 빈 배경 | 모바일 이미지 |
| 업로드 | 업로드 | PC 이미지 | 모바일 이미지 (override) |
