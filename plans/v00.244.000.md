# v00.244.000 — 가독성 + 조회수 root cause 묶음

## 사용자 요청 (3건)
1. 강연 미리보기 가독성 개선 (스크린샷: 카드 제목이 옐로우로 강제 노출)
2. PC 게시글 상세 제목 60% 축소
3. 게시글 조회수가 안 올라감 — 검토

## 진단

### A. 강연 카드 제목 옐로우 (KMS §2 위반)
- [styles.css:165-166](styles.css#L165-L166):
  ```css
  :root[data-theme="dark"] .gold,
  :root[data-theme="dark"] .ko-serif { color: var(--primary); }
  ```
- `.ko-serif` 가 사이트 전체 180+ 곳 사용. 다크모드에서 모두 옐로우 강제.
- KMS §2 5% 룰 + memory `feedback_color_system` 정면 위반. 진원지.

### B. PC 게시글 제목 사이즈
- [CommunityPage.jsx:1378](pages/CommunityPage.jsx#L1378): `clamp(28px, 3.5vw, 44px)`
- PC max 44px → 60% = 약 26px

### C. 조회수 root cause (server-side 미구현)
- `BGNJ_COMMUNITY.incrementViews` ([data.js:1560](data.js#L1560)) → `updatePost({views})`
- `updatePostRemote` apiPatch ([data.js:1495-1502](data.js#L1495-L1502)) — views 필드 화이트리스트 누락 → 서버 도달 X
- worker `handlePostView` endpoint **없음** (칼럼은 [workers/src/index.js:1996](workers/src/index.js#L1996) 에 있는데 게시글은 누락)
- 결과: 게시글 조회수 영구 0 (작성 시점 빼고)

## 변경

### 1. styles.css (다크모드 ko-serif 옐로우 강제 해제)
```css
- :root[data-theme="dark"] .gold,
- :root[data-theme="dark"] .ko-serif { color: var(--primary); }
+ :root[data-theme="dark"] .gold { color: var(--primary); }
+ /* .ko-serif 는 기본 ink 유지 — 옐로우는 .gold opt-in 으로 분리 (KMS §2 5% 룰) */
```

### 2. CommunityPage.jsx 제목 축소
```jsx
- fontSize:'clamp(28px, 3.5vw, 44px)'
+ fontSize:'clamp(22px, 2vw, 26px)'  // PC 44→26 (~60%)
```

### 3. 게시글 조회수 — 3-점 fix
- **api.js**: `posts.view(id)` endpoint 추가 (칼럼과 동일 시그니처)
- **workers/src/index.js**: `handlePostView` + 라우터 추가 (★ wrangler deploy 필요)
- **data.js BGNJ_COMMUNITY.incrementViews**: 칼럼 패턴 미러 — `BGNJ_API.posts.view(id)` 호출 + `_serverPosts` 캐시 동기 + 폴백 (워커 미배포 시 클라 optimistic 만)
