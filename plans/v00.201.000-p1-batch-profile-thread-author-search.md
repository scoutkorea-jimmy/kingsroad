## 작업 묶음 (4건)

### v00.201 — P1 #3: 마이페이지 프로필 / 비밀번호 변경 UI
- 워커는 이미 `PATCH /api/me` 존재 → UI 만 추가
- 마이페이지에 새 카드: [프로필 수정] / [비밀번호 변경] 두 모달
- 프로필: 이름, 프로필 사진(R2), 자기소개
- 비밀번호: 현재 비번 + 새 비번 + 확인. 워커 측 검증 (handleAuthLogin 의 hash 함수 재사용 가능)
- 워커: `PATCH /api/me/password` 추가 필요할 수도 — 확인 후 결정

### v00.202 — P1 #5: 답글 트리 (커뮤니티 댓글)
- D1.comments 에 `parent_id` 컬럼 추가 (schema migration)
- 워커 handleCommentsCreate 에 parent_id 입력 받기
- handleCommentsList 에 parent 그래프 응답
- 클라: 댓글 카드에 [답글] 버튼 → 들여쓰기된 답글 입력 폼
- 표시: 답글은 indent + ↳ 표시. 깊이 1단계만 (트리 무한 깊이 X)

### v00.203 — P1 #6: 작성자 프로필 페이지
- 새 라우트 `/u/:userId` (또는 해시 #user-{id})
- 워커: `GET /api/users/:id/profile` (public — 이름/프로필 사진/자기소개/등급 + 작성 글/칼럼 카운트)
- 클라: AuthorPage 컴포넌트
- 글/댓글의 작성자 이름 클릭 시 점프

### v00.204 — P1 #4: 본문 검색
- 워커 handlePostsList SQL 에 `body LIKE '%q%'` 추가 (현재 title/author 만)
- 칼럼: workers handleColumnsList 도 body LIKE 옵션
- 클라: 검색 UI 에 "본문 포함" 체크박스 (기본 false → on 시 워커가 body 검색)
- 인덱싱은 후속 (현재 LIKE 로 충분)
