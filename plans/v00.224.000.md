# v00.224.000 — 모바일 sticky 카드 3건 일괄 해제 (스크롤 가림 방지)

## 사용자 검증 질문
> 모바일 기능으로 스크롤 했을 때 화면을 가려서 정보를 못보게 되거나 이런건 없다는 말이지?

## 진단 결과 (3건 발견)
v00.221 에서 도서 표지 카드(`book-cover-col`)는 모바일 sticky 해제 처리됐지만, 같은 패턴의
다른 sticky 카드 3건이 여전히 모바일 1열 스택 시 콘텐츠를 가리는 문제 남아있음:

| 페이지 | 카드 | 위치 |
|---|---|---|
| 강연 | NEXT SCHEDULE | LecturesPage.jsx:348 |
| 투어 | NEXT SCHEDULE | WangsanamTourPage.jsx:358 |
| 결제 | ORDER SUMMARY | BookCheckoutPage.jsx:712 |

모두 `style={{position:'sticky', top:100}}` — 데스크톱 2열 레이아웃 가정. 모바일에서
1열로 스택될 때 sticky 가 활성화되어 첫 행 카드가 nav 아래 100px 위치에 붙어버려
두 번째 행(상세 정보/폼/주문 입력) 진입을 막음.

## 수정 방안

공통 패턴: `book-cover-col` 처럼 데스크톱은 sticky 유지, 모바일만 풀어주기.

1. 3개 카드에 공통 className `mobile-release-sticky` 부여
2. styles.css 에 단일 규칙 추가:
   ```css
   @media (max-width: 900px) {
     .mobile-release-sticky { position: static !important; top: auto !important; }
   }
   ```

## 변경 파일
