## 3. 카루셀 슬라이드 디자인

```jsx
<div style={{position:'relative', minHeight: ...}}>
  {books.map((b, i) => {
    const active = i === idx;
    return (
      <div key={b.id} style={{
        position: i === 0 ? 'relative' : 'absolute',
        top: 0, left: 0, right: 0,
        opacity: active ? 1 : 0,
        transform: active ? 'translateX(0)' : (i < idx ? 'translateX(-24px)' : 'translateX(24px)'),
        transition: 'opacity .55s ease, transform .55s ease',
        pointerEvents: active ? 'auto' : 'none',
      }}>
        ... 카드 ...
      </div>
    );
  })}
</div>
```

- `i === 0` 만 relative → wrapper 가 첫 카드 높이 보존. 책마다 높이 비슷 (cta-grid 1fr 1fr) 이라 OK.
- 무한 wrap 시 jump 없음 (단순 fade + 작은 shift).
- prefers-reduced-motion 존중 — transition 비활성.

## 4. 한 줄 소개

`book.subtitle` 표시. title 아래에 작은 italic 또는 dim color. desc 는 그대로 본문에 길게 (현행 유지).

```jsx
<h2 style={{...}}>『{cur.title}』</h2>
{cur.subtitle && (
  <p className="dim" style={{
    fontFamily:'var(--font-serif)', fontSize:18,
    fontStyle:'italic', marginBottom:20, lineHeight:1.5,
  }}>{cur.subtitle}</p>
)}
{cur.desc && <p>...desc...</p>}
```

## 5. BookPage hero

다권 탭 (line 127-) 위에 hero 영역 신설:

```jsx
<div style={{textAlign:'center', marginBottom: 48}}>
  {(() => {
    const _i = (window.BGNJ_SITE_CONTENT?.get?.() || {}).bookIntro || {};
    const eb = _i.eyebrow || 'BOOKS · 뱅기노자 도서';
    const tp = _i.titlePrefix ?? '';
    const ta = _i.titleAccent ?? '뱅기노자';
    const ts = _i.titleSuffix ?? '가 짓다';
    const sb = _i.subtitle || '한국의 역사와 풍경을, 책으로.';
    return (
      <>
        <div className="section-eyebrow" style={{justifyContent:'center'}}>{eb}</div>
        <h1 className="section-title">{tp}<span className="accent">{ta}</span>{ts}</h1>
        <p className="section-subtitle" style={{margin:'16px auto 0'}}>{sb}</p>
      </>
    );
  })()}
</div>
```

- 카루셀의 absolute layered 카드는 책별 높이 다르면 wrapper 가 첫 카드 기준 → subtitle/desc 길이 차이 시 wrapper 가 잠깐 잘림 가능. 책 데이터 패턴이 비슷할 거라 1차는 수용. 신호 시 `min-height: max(...)` 추가.
