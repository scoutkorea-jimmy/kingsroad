LecturesPage 는 이미 [v00.129 시점](../pages/LecturesPage.jsx#L31-L41)에 `upcoming`/`past` 버킷 분리 + past startsAt DESC 정렬 + 기본 bucket='upcoming'. **투어만 미적용**.

## 변경 방안

### 1. WangsanamTourPage — LecturesPage 와 동일한 버킷 패턴 이식

- `bucket: 'upcoming' | 'past'` state 추가, 기본 `'upcoming'`
- `_now`/`_yesterday` 기준 `_isPast` 헬퍼 — startsAt 없으면 upcoming (LecturesPage 와 동일 룰)
- `toursUpcoming` = filter !_isPast, **startsAt ASC** 정렬 (가장 가까운 미래가 먼저)
- `toursPast` = filter _isPast, startsAt DESC 정렬
- 기존 탭 UI는 그대로 (각 버킷 안의 투어 탭) — 큰 UX 변경 없음
- 버킷 토글 칩 추가 (LecturesPage 와 동일 스타일)
- bucket 전환 시 `selectedIdx=0`
- 외부 진입(sessionStorage tour id) 시 두 버킷 모두 검색 → 적절한 버킷으로 이동
- v00.236 동기화 listener + admin includeHidden 옵션 유지

### 2. 정원 라벨 정합 — 표시 시점에 capacity 우선

[WangsanamTourPage.jsx:222](../pages/WangsanamTourPage.jsx#L222) 에서:

```js
const groupLabel = Number.isFinite(Number(tour.capacity)) && Number(tour.capacity) > 0
  ? `${tour.capacity}인 이하`
  : (tour.group || '소규모');
```
→ capacity 가 있으면 항상 capacity 따라 표시. group 은 capacity 없을 때만 fallback.
→ admin 이 capacity 만 바꿔도 라벨이 자동 정합.

기존 `tour.group` schema 는 유지 (legacy 호환, admin 입력란도 유지) — 표시 우선순위만 변경.
