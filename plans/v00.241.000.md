## 오류 로그 — 사용자 질문 응답
오류 로그 (BGNJ_ERROR_LOG → 워커 `/api/admin/error-log`) 는 **자동 캡처
시스템** 입니다. window.onerror / unhandledrejection 핸들러가 모든 런타임
오류를 D1 `error_log` 테이블로 push 하고, admin 패널 → 시스템 → 오류 로그
탭에서 검색·필터링 조회 가능. 코드 변경마다 수동으로 갱신할 필요 없음.

직접 확인 — 브라우저 콘솔에 `await BGNJ_API.admin.errorLog.list({limit:10})`
또는 admin 패널 시스템 → 오류 로그 탭에서 최근 에러 확인. v00.231 에서
도입한 console.warn (`[BGNJ_X.method] non-array — cache preserved`) 도
동일 캡처 흐름.
