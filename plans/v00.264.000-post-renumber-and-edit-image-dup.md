# v00.264.000 — 게시글 번호 클릭으로 순서 변경 + 수정 시 첨부 이미지 본문 중복 삽입 차단

## 사용자 요청 원문

> 게시글의 번호를 변경해서 게시글 업로드 순서를 바꿀 수 있는 기능 추가. 사용자가 작업하기 편하게 적용할 것.
>
> 그리고 이미지가 포함 된 게시글 작성 후 수정할 때 첨부 된 이미지가 본문에 자동으로 삽입되는것도 수정.

## 진단

### A. 게시글 번호 = 파생 값

[CommunityPage.jsx:892](../pages/CommunityPage.jsx#L892):
```js
const rowNum = String(filtered.length - (pageStart + i)).padStart(3, '0');
```
- "번호" 컬럼은 저장된 필드가 아니라 정렬된 목록의 역순 인덱스. 즉 목록 첫째 줄(=가장 최신)이 가장 큰 번호.
- 정렬은 기본 `latest` = `createdAt` desc. 번호 변경 = `createdAt` 재배치.

### B. createdAt 수정 인프라 보유

- [data.js:1542](../data.js#L1542) — `updatePostRemote` 가 `createdAt` 패치 가능 (워커가 admin 만 허용).
- 따라서 새 D1 컬럼/워커 배포 없이도 admin 이 createdAt 만 바꾸면 번호가 즉시 재배열.

### C. 수정 시 본문에 첨부 이미지 중복 노출 (회귀)

발견 경로 ([CommunityPage.jsx:1138-1149](../pages/CommunityPage.jsx#L1138)):
1. 새 글 발행 시 `_attachedImagesHtml` 블록(`<div data-bgnj-attached-block="1">…</div>`)을 본문 끝에 append → D1 저장.
2. 같은 글 수정 시 [CommunityPage.jsx:1105](../pages/CommunityPage.jsx#L1105) `setBodyHtml(initialPost?.body?.html || "")` 가 append 된 블록 포함 그대로 Tiptap 에 로드 → 본문 영역에 이미지가 inline 으로 보임.
3. 사용자가 수정 → 발행 시 `bodyHtml`(이미 이미지 블록 포함) + 새 `_attachedImagesHtml` (= images 배열 그대로 다시 직렬화) → 중복 누적.

**원인:** v00.242 워커 비배포 회피책으로 본문 끝 append 채택했으나 수정 라운드트립에 idempotent 가 아님.

**최소 수정:** 수정 시 `initialPost.body.html` 에서 append 블록을 strip 한 채 Tiptap 에 로드 + 새 발행 직전에도 한 번 더 strip 후 append (이중 안전).

## 변경 방안

### 1) 번호 클릭 = 순서 변경 (관리자 전용)

`pages/CommunityPage.jsx` 의 테이블 행 번호 셀:
- admin && `sort === 'latest'` 일 때만 번호를 버튼으로 노출 (다른 정렬은 createdAt 와 무관하므로 비활성).
- 클릭 → `BGNJ_PROMPT`/`window.prompt` 로 "새 번호 (1 ~ {filtered.length})" 입력.
- 입력값을 정수로 검증 → 목표 인덱스 idx = filtered.length - newNum (0-based, latest 정렬 기준).
- **createdAt 계산 규칙:**
  - idx === 0 (= 최상단): `filtered[0].createdAt + 1초`.
  - idx === filtered.length - 1 (= 최하단): `filtered[last].createdAt - 1초`.
  - 그 외: 인접 두 항목 createdAt 의 중간값. 동률이거나 1초 미만 간격이면 ±0.5초 보정.
- `updatePostRemote(post.id, { createdAt: iso })` 호출 → `refreshPosts` 자동.
- 진행 토스트: "게시글 순서를 변경했습니다. (n번 → m번)".

힌트 노출: 헤더 옆에 admin 만 보이는 안내 "번호 클릭으로 순서 변경" 1줄.

### 2) 수정 시 본문 중복 차단

`pages/CommunityPage.jsx`:
- 헬퍼 `_stripAttachedBlock(html)` 추가: `<div data-bgnj-attached-block="1">…</div>` 한 단위 제거 (DOMParser 사용, 실패 시 정규식 폴백).
- [line 1105](../pages/CommunityPage.jsx#L1105) — `setBodyHtml(_stripAttachedBlock(initialPost?.body?.html || ""))`.
- [line 1149](../pages/CommunityPage.jsx#L1149) — `const _bodyHtmlWithImages = _stripAttachedBlock(bodyHtml) + _attachedImagesHtml;` (이중 안전 + 사용자가 본문 inline 으로 이미지를 옮긴 경우에도 첨부 블록만 청소).
- 사이드 이펙트: 사용자가 본문에 inline 으로 삽입한 `<img>` 는 `data-bgnj-attached-block` 마커가 없으므로 유지됨.

## 남은 위험

- prompt 가 모바일 UX 가 거칠다. 1차에는 prompt 로 빠르게 도입하고, 사용자 신호 시 모달/드래그 UI 로 확장.
