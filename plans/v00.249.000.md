# v00.249.000 — 모바일 히어로 가독성 + 풍성함 보강

## 사용자 보고
> 글씨의 가독성이 떨어지는데 이건 개설할 수 있는 방법이 없나? 그리고 뭐랄까... 메인에 비해서 빈약하고 조악해보인다고해야하나

## 진단 (2건)

### A. 모바일 hero 텍스트 가독성 부족
배경 이미지 위에 텍스트가 직접 올라감 → 한국풍 일러스트의 흰 구름·옅은 영역과 텍스트가 겹쳐 contrast 부족. 특히 "한국을" (옐로우, 흰 구름 위) 가 거의 안 보임.

### B. 메인(PC) 대비 빈약
- PC: `1.2fr 1fr` 2-col → 좌측 풍성한 스토리텔링 + 우측 정보 카드. 텍스트/스탯/CTA 가 좌측에서 압축돼 풍성.
- 모바일(≤900px): 1-col stack. **통계가 [styles.css:1684](styles.css#L1684) 에서 3열→1열 폴백** → 짧은 라벨 3개가 세로로 길게 늘어져 빈약 인상.

## 변경

### 1. 모바일 그라디언트 오버레이 (가독성)
- HomePage.jsx — `<section>` 에 동적 클래스: `home-hero ${hasBg ? 'has-bg' : ''}`
- styles.css 신규:
  ```css
  @media (max-width: 600px) {
    .home-hero.has-bg::before {
      content: ''; position: absolute; inset: 0; z-index: 0;
      background: linear-gradient(180deg,
        rgba(255,255,255,0.88) 0%,
        rgba(255,255,255,0.65) 35%,
        rgba(255,255,255,0.25) 65%,
        rgba(255,255,255,0) 90%);
      pointer-events: none;
    }
  }
  ```
- 다크모드 분기 (slate 945 톤)

### 2. 통계 3열 유지 (풍성함)
- styles.css 기존 1684 라인의 `.hero-stats { grid-template-columns: 1fr }` → `repeat(3, 1fr)` 강제 유지
- gap 14 → 12 (좁은 폭에 맞춰)

### 3. 모바일 padding 보강
- 기본 `72px 0 88px` 유지 (PC). 모바일 ≤600px 에서만 `60px 0 72px` 로 미세 조정해 호흡 정합

## 변경 파일
- `pages/HomePage.jsx` — section 클래스 1줄
- `styles.css` — 모바일 has-bg ::before 오버레이 + hero-stats 3열 + padding
- `data.js` / `version.json` / `index.html`

## 효과
- **가독성**: 흰 그라디언트가 상단~중단 (텍스트 영역) 에 깔리며 contrast 보장. 배경 이미지 하단 (한옥/타워 등) 은 그대로 살아남
- **풍성함**: 통계 3열 가로 압축으로 시각 밀도 회복
- 다크모드 자동 분기
