# v00.250.000 — 히어로 다크모드 라이트 텍스트 강제 + 위계 회복

## 사용자 보고 (3건 누적)
1. (v00.249 후) 위계 헷갈림 — 모바일에서 강연/답사 카드가 hero title 보다 강함
2. **PC 다크모드에서 글씨 안 보임** (방금 스크린샷)
3. **히어로 세션은 다크모드에서도 기본 스타일 유지하길 원함**

## 진단

배경 이미지가 **라이트 톤 한국풍 일러스트** (베이지/흰/옐로우). 다크모드 텍스트는 흰색 톤(`--ink: #F1F5F9`) → **흰 위 흰** 으로 안 보임. v00.249 의 모바일 흰 그라디언트는 적용됐지만:
- 다크모드 분기 자체가 다크 그라디언트 → 흰 텍스트 회복 안 됨
- PC 모바일 그라디언트 미적용 → 그대로 안 보임

## 변경

### 1. 히어로 안에서만 다크모드 → 라이트 토큰 매핑 (사용자 핵심 요청)
```css
:root[data-theme="dark"] .home-hero.has-bg {
  --ink:   #0F172A;
  --ink-2: #334155;
  --ink-3: #64748B;
}
```
inline `color: var(--ink)` 들이 자동으로 라이트 톤 따라옴 (CSS 변수 cascade). PC/모바일 동시 적용. has-bg 일 때만 (배경 미설정 hero 는 다크 그대로 유지).

### 2. 모바일 그라디언트 다크모드 분기 제거
v00.249 의 다크 그라디언트 → 라이트 흰 그라디언트로 통일 (배경이 라이트 톤이므로 항상 흰 fade 가 자연스러움).

### 3. HeroProgramCards 모바일 위계 톤다운 (이전 보고 처리)
- `.home-program-card h3` 모바일 `font-size: 20px` → `17px`
- 카드 padding 22/24 → 18/20 (전체 prominence 톤다운)
- hero title 이 시각 위계 1순위로 회복

## 변경 파일
- `styles.css` — 다크모드 토큰 매핑 + 그라디언트 통일 + HeroProgramCards 톤다운
- `data.js` / `version.json` / `index.html`
