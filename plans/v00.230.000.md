# v00.230.000 — 노란글씨 가독성 hotfix (Primary on white = AA 위반)

## 사용자 보고
> 노란글씨는 잘 안보여 (스크린샷: /lectures 강연 페이지)

화면에서 잘 안 보이던 노란 텍스트들:
- 버킷 토글 활성 라벨 (`진행 예정 강연 (1)`)
- 탭 활성 (`01 · 왕의 길을 설계하라`)
- 사이드바 본문값 (`15,000원`, `30석`, 진행 호스트명)
- badge `왕의 길을 설계하라` (옐로우 위 옅은옐로우 = 거의 안 보임)

## 원인
Primary 옐로우 `#F5D548` 는 흰 배경에서 대비비가 ~1.7:1 (WCAG AA 의 4.5:1 한참 미달).
KMS §2 컬러원칙은 "Primary 5% — CTA·focus·active dot 만" 이지만 실제로 본문/본문강조에
인라인 / 클래스(`.gold`, `.gold-2`, `.accent`, `.badge-gold`) 로 대량 침투했음.

## 수정

### 1. `styles.css` 클래스 정의 일괄 교체
- `.gold` `var(--primary)` → `var(--secondary)` (Caramel Ink #92400E, AAA 대비)
- `.gold-2` `var(--primary-hover)` → `var(--secondary-hover)` (#7C2D12)
- `.section-title .accent` → `var(--secondary)` italic
- `.badge-gold` 텍스트 → `var(--secondary)` (테두리는 옐로우 유지 = 브랜드 시그너처)
- 다크모드 override (`:root[data-theme="dark"] .gold` 라인 165-166) 그대로 유지 →
  어두운 배경에서는 옐로우 가독성이 좋아 기존 동작 보존.

### 2. `pages/LecturesPage.jsx` 인라인 수정
- 버킷 토글 활성 텍스트 색
- 탭 활성 텍스트 색 (하단 indicator 는 옐로우 유지)
- FREE pill 텍스트
- 잔여 좌석 수 텍스트 (full 시 danger 분기 유지)
- `tone()` 의 `confirmed` → secondary

### 3. `pages/WangsanamTourPage.jsx` 인라인 수정
- 멤버 카드 mono spec 라벨
- 탭 활성 텍스트
- 잔여 텍스트
- `tone()` 의 `confirmed` → secondary

## 자동 파급
`.gold` / `.gold-2` 가 사이트 전반의 `gold-2 ko-serif` 가격 표시, `gold mono`
메타 텍스트 등에 사용되므로 LecturesPage 외에도 ColumnPage / MyPage / TourPage /
HomePage / CommunityPage 등 모든 곳의 본문 옐로우가 동시에 secondary 로 전환.
