# v00.206+ — 레거시 컬러 토큰 마이그레이션 (--gold/--cta-* → --primary*)

## 배경
v2 컬러 시스템(--primary / --secondary / --tertiary / --on-primary 5:25:70 황금 배색) 도입 후, 레거시 토큰(--gold / --gold-dim / --gold-ink / --cta-rest / --cta-hover / --cta-active) 은 styles.css 에 alias 형태로만 유지되며 코드 전역에서 여전히 사용 중. 가이드(AdminDesignHub) 는 v2 토큰만 노출하도록 정리되었으나 코드와의 정합은 미완료.

## 작업 범위

### 1. 자동 grep + 수동 분류
- `grep -rn "var(--gold\b\|var(--gold-dim\|var(--gold-ink" pages/ components/`
- `grep -rn "var(--cta-" pages/ components/`
- 결과를 카테고리별 분류:
  - 인라인 style — 1:1 토큰 교체
  - 클래스 (.gold / .ko-serif gold 등) — 정의는 styles.css 에서 var(--primary) 로 변경
  - 인라인에서 의도적 다른 색상 (--gold-dim 의 옅은 옐로우 강조 등) — `--primary-dim` 으로 매핑

### 2. 매핑 표
| 레거시 | 신규 |
|---|---|
| `--gold` | `--primary` |
| `--gold-dim` | `--primary-dim` |
| `--gold-ink` | `--on-primary` |
| `--cta-rest` | `--primary` |
| `--cta-hover` | `--primary-hover` |
| `--cta-active` | `--primary-active` |

### 3. 점진 마이그레이션 (3단계)
- Step 1: `pages/AuthAdminPage.jsx`, `pages/admin/*` (관리자 영역)
- Step 2: 일반 페이지 (`HomePage`, `CommunityPage`, `MyPage` 등)
- Step 3: styles.css 의 alias 제거 (마지막 사용처 확인 후)

### 4. 산출물
- 레거시 토큰 사용 0건 (Step 3 완료 시점)
- styles.css `:root` 의 alias 라인 (현재 약 10줄) 제거
- 가이드의 "레거시 호환 alias" 주석 삭제

- 각 단계 후 라이브 사이트 시각 비교 (특히 hover/active 상태)
