## 4. focus trap 설계

```js
React.useEffect(() => {
  if (!open) return;
  // 직전 focus 보존 (모달 닫힐 때 복원).
  const prevFocus = document.activeElement;
  // 컨테이너 찾기 — contentRef > role=dialog > data-bgnj-modal 우선순위.
  const container = contentRef?.current
    || document.querySelector('[role="dialog"][aria-modal="true"]')
    || document.querySelector('[data-bgnj-modal="true"]');
  if (!container) return () => {};
  const FOCUSABLE = 'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])';
  const list = () => Array.from(container.querySelectorAll(FOCUSABLE))
    .filter((el) => !el.disabled && el.offsetParent !== null);
  // 첫 focus.
  const first = list()[0];
  if (first && !container.contains(document.activeElement)) {
    try { first.focus(); } catch {}
  }
  // Tab cycle.
  const onKey = (e) => {
    if (e.key !== 'Tab') return;
    const fs = list();
    if (fs.length === 0) return;
    const f = fs[0], l = fs[fs.length - 1];
    const a = document.activeElement;
    if (e.shiftKey && a === f) { e.preventDefault(); l.focus(); }
    else if (!e.shiftKey && a === l) { e.preventDefault(); f.focus(); }
  };
  container.addEventListener('keydown', onKey);
  return () => {
    container.removeEventListener('keydown', onKey);
    try { prevFocus?.focus?.(); } catch {}
  };
}, [open, contentRef]);
```

호환성:
- 5 호출 사이트 ([HomePage.jsx:15,113](pages/HomePage.jsx#L15) + [AuthAdminPage.jsx:8,4446](pages/AuthAdminPage.jsx#L8)) 변경 0
- 폴백 selector 가 매치 못하면 trap 비활성 → 회귀 0
- 점진적 활성화: 호출 사이트가 dialog 에 `role="dialog" aria-modal="true"` 부착 시 자동 적용. 미부착 컴포넌트도 안전.
