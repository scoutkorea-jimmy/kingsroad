- "홈넥스트 히어로페이지 우측으로 쳐졌다" — 히어로가 뷰포트 전체 높이를 채우며 콘텐츠가
  큰 여백 속에 가운데로 가라앉아(align-items:center) 보임 + 헤드라인이 깨져 보임.
- "텍스트 크기나 이런 것들이 비합리적" — 타입 스케일/간격 개선 요청.

## 진단 ([pages/HomeNextPage.jsx](../pages/HomeNextPage.jsx) + [styles.css](../styles.css) 2360~2413)
1. **헤드라인 단어 깨짐** — `.hn-h1` 에 `word-break` 미지정 → "사람을 만나는 인문기행"이
   540px 컨테이너를 넘쳐 "인문기/행" 으로 음절 분리. 한글은 keep-all 필요.
2. **CTA 아이콘 빈 회색 박스** — `ctaIcons[i]` 미업로드 시 `.hn-cta-pill-ph`(36px 회색
   사각형)를 렌더 → 깨진 이미지처럼 보임.
3. **히어로 과대 높이** — `.hn-page` min-height:calc(100vh-72px) + `.hn-hero` flex:1 +
   align-items:center → 콘텐츠가 거대한 빈 공간 한가운데 떠서 "쳐진" 느낌.
4. **타입 스케일 점프** — h1 clamp(…,46px) ↔ lead 18 ↔ sub 14. 위계 점프가 급격.

## 수정
1. `.hn-h1` — `word-break:keep-all` + 단어 단위 줄바꿈, clamp 상한 46→40px 로 완화,
   행간/자간 정리. `.hn-hero-inner` max-width 540→600px 로 헤드라인 1줄 여유 확보.
2. CTA 아이콘 — 미업로드 시 placeholder 박스 미렌더 (텍스트-only pill). JSX 조건부 렌더.
3. 히어로 수직 정렬 — align-items:center → flex-start + 합리적 상단 패딩으로 콘텐츠를
   상단-중상단에 배치 (거대 여백 가라앉음 방지). hero 최소 높이 적정화.
4. 타입 스케일 — lead/sub clamp 상향 미세 조정 + 간격 리듬 정리(8/12/20 단위).
