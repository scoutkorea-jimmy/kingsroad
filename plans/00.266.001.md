# v00.266.001 — 놀자 드롭다운 오버플로우 탈출 + 홈 투어/강연 날짜 필터

## 1. 상단 네비 "놀자" 드롭다운이 .nav-menu 안에 갇혀 잘림
- 원인: `.nav-menu { overflow-x:auto }` (가로 슬라이드) → 자식 absolute 드롭다운의 세로 넘침도 클리핑.
  사용자: "서브 메뉴는 저 영역 밖까지 나와서 보여야 하지 않냐. 스크롤해서 보니 알았다."
- 해결 (components/Shell.jsx): 놀자 메가를 `position:fixed` + 버튼 `getBoundingClientRect` 로 좌표 JS 계산 →
  오버플로우 컨테이너 밖으로 렌더. 호버(onMouseEnter/Leave, 140ms 닫힘 지연) + 클릭 토글 통일.
  바깥클릭/Esc/스크롤 시 닫힘. styles.css 의 generic hover 룰에서 `.nav-mega-play` 제외(:not).

## 2. 홈 "이번에 함께 걸을 길"(투어) — 지난 일정이 계속 노출됨
- 원인: HomePage 의 `tours`(기존 652행)가 `!hidden` 만 필터, 날짜 미적용. (HeroProgramCards 는 이미 필터 O)
- 해결 (pages/HomePage.jsx): `tours` 를 예정(어제 이후)만 + startsAt 정렬 + slice(4).
  섹션은 항상 노출하되 예정이 없으면 "이번에 함께 걸을 길이 아직 없습니다" 빈 상태 안내(지난 일정 노출 금지).

## 3. 홈 "앉아서 먼저 떠나는 시간"(강연) — 지난 강연이 그대로 노출됨
- 해결: `lectures` 를 예정 우선, 없으면 가장 최근 지난 강연 3개로 폴백(v00.129 사용자 요청 유지).
  폴백 모드(`lecturesArePast`)면 헤더에 "현재 예정된 강연이 없어 지난 강연을 보여드립니다" 안내 +
  각 카드에 "지난 강연" 배지(per-card `isPast`).
