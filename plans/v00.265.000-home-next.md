# v00.265.000 — 신규 홈페이지 프리뷰 (/home-next)

## 사용자 요청

> 첨부 이미지 기반 홈페이지 재구성. 스크롤 없이 한 화면에 모든 것을 담는 레이아웃.
> 기존 메인(/) 은 건드리지 않고, /home-next 임시 라우트로 시각 검토 후 교체.

## 디자인 이미지 분석 (4 섹션, 1 viewport)

### 1. Hero (뷰포트 ~55%)
- 전폭 배경 이미지 (한옥/궁궐 + 사람들, 따뜻한 금빛 톤)
- 좌측 텍스트:
  - 대제목 3줄: "시간을 걷고," / "역사를 기록하고," / "사람을 만나는 인문기행" (마지막 줄 accent)
  - 볼드 부제: "뱅기노자는 현대의 사관입니다."
  - 설명문: "조선의 사관이 시대를 기록했듯, ..."
  - CTA 4개 (아이콘+텍스트, 둥근 사각): 현대 사관 모집 / 탐방 프로그램 신청하기 / 출간 실록 (도서) / 영상 실록 (유튜브)

### 2. 프로그램 카드 4열 (뷰포트 ~15%)
- 탐방 프로그램: 따뜻한 갈색 톤 bg, "왕의 길을 따라 역사 속 현장을 걷다"
- 출간 실록: 크림 bg + 책 표지 이미지, "우리가 기록한 역사의 순간들"
- 언론 기록: 밝은 bg + 신문/로고, "언론이 기록한 뱅기노자의 발자취"
- 영상 실록: 다크 bg + YouTube 재생, "5분 역사 이야기부터 현장 탐방 영상까지"

### 3. 통계 5열 (뷰포트 ~10%)
- 사초(기록) 1,200+ / 탐방 프로그램 40+ / 참여한 사관 3,000+ / 언론 보도 100+ / 나눔과 기부 20%

### 4. 하단 CTA 3열 (뷰포트 ~20%)
- 좌: 인용문 "한 걸음의 기록이 한 시대의 기억이 됩니다." + 장식 이미지
- 중: 소개 텍스트 + "뱅기노자 소개 보기 →"
- 우: "현대 사관이 되어주세요" + "현대 사관단 가입하기 →" CTA

## 구현 방안

1. `pages/HomeNextPage.jsx` 신규 생성 — 4 섹션 고정 레이아웃
